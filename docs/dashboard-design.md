# 我的看板：可讀性調整紀錄

## Overview

本次採 Impeccable **Operate mode**，範圍僅為既有看板的閱讀層次與資訊揭露。使用者要求「字少一點、比較好閱讀」；沿用現有深色介面，不建立新視覺識別或全站設計系統。此文件是局部畫面紀錄，不替代產品規格；目前沒有 `PRODUCT.md` 或 `DESIGN.md`。

實作來源：`src/app/dashboard/page.tsx`、`src/components/dashboard/PersonalAssignments.tsx`、`src/components/dashboard/LineNotificationPreference.tsx`。資料語意、操作目的地與角色限制維持原有規則。

## Colors

沿用 `tailwind.config.js` 的 `mc-*` 色彩。背景、卡片與文字分別使用 `mc-bg`、`mc-card`、`mc-text`；次要文字使用文字色的 70% 透明度，分隔線使用白色的 10%。連結與選取狀態沿用藍色，待處理提示沿用琥珀色，通知開啟狀態沿用綠色。未新增全域色票或修改公告頁的主題變數。

## Typography

沿用 Tailwind 預設無襯線字體堆疊與系統中文字型回退，未載入新字體。頁面標題為 24px 半粗體；委派標題為 20px，地圖與交接區標題為 18px。委派名稱使用 16px、寬鬆行高；狀態與操作使用 14px，年份與來源分類使用 12px。日期與數量採等寬數字，長名稱可換行。

## Layout

沿用 `DashboardLayout` 的側欄與行動版頂列。內容置中、最大寬度 64rem，內距在小螢幕為 16px、768px 起為 32px；主要區段間距由 32px 增為 40px。以分隔線與留白組織內容，減少卡片內重複文字。

委派依起日與迄日的組合分組排列：日期在左，名稱與角色在右；每組來源分類去重後只顯示一次。左欄由 4.5rem 增至 5.5rem，右欄允許縮小與換行。初始顯示前三個日期組，同日委派不拆散。

## Elevation & Depth

提供淺色、深色與跟隨裝置三種外觀，與公佈欄共用本機偏好；沿用低對比邊線與局部卡片底色；本次未新增陰影層級。互動回饋沿用淡色背景、文字色變化與展開箭頭旋轉。

## Shapes

沿用圓角連結與狀態區塊（8px／12px），LINE 通知按鈕維持膠囊形狀。主要操作至少高 44px，委派內容列至少高 56px；地圖摘要保留更寬鬆的垂直空間。

## Components

- **閱讀順序**：個人委派先呈現；管理員接著看到既有任務中心；列為派發人選的成員再看到交接與地圖；通知與管理工具位於頁尾。
- **委派**：更多日期組、過去委派與資料確認提示使用原生 `details`／`summary`。展開後保留所有項目，歷史資料不刪除；項目保留來源連結，週中委派可開啟當週節目表；分類按鈕原頁切換。弟兄服務與節目分類維持原有可見性；姊妹只顯示節目委派。
- **交接與地圖**：摘要先顯示名稱、狀態及持有天數；展開後顯示日期、下一位、回報與原有操作。管理／傳道進度、小地圖及提交回報入口保留；小地圖仍遵守既有圖號條件。
- **角色**：`showTerritory` 決定領圖、地圖與交接區可見性；一般使用者的交接區維持非管理員條件。管理員任務中心仍直接呈現，同步與 LINE Bot 管理工具收進「管理工具」。折疊不改變授權。
- **通知**：「通知內容」預設收合，開關直接可用。讀取中、儲存中、未綁定 LINE、失敗與完成訊息維持可見，狀態訊息保留 `role="status"`。
- **其他狀態**：保留載入提示、讀取錯誤與重試、沒有委派、沒有地圖、沒有待交接與沒有歷史紀錄的文字。載入動畫遵守減少動態效果偏好。

## Do's and Don'ts

- 保持「先看摘要，再展開細節」；收合內容仍須能找到完整操作與歷史。
- 優先消除重複來源、日期與說明，不以刪除業務資料換取簡潔。
- 沿用既有色彩、字體與權限；本次畫面規則不自動推廣成全站規範。

驗證紀錄：本次執行的 Impeccable detector 回傳 `[]`；以合成資料進行的瀏覽器介面檢查於 320、768、1440px 通過，包含一般使用者、姊妹與管理員畫面。這是局部檢查結果，不代表完整無障礙稽核。
