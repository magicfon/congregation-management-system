# ADR-0009：從三張原圖重建像素分區草稿

日期：2026-09-20
狀態：實驗，正式資料尚未替換

## 需求

使用者要求重新嘗試三張大區域地圖的 polygonize，建立 JSON 或提出適合的分區格式。

## 決策

- 直接使用楠梓、橋頭、梓官原始 PNG 的淡紫色分區線，輸出獨立候選檔。
- 採用明確標示 image-pixel、左上原點、向下 y 軸的 `[x,y]` JSON；提供 SVG 疊圖供核對。未地理定位前不當作經緯度 GeoJSON。
- 原圖人工判讀的編號位置僅作為配對線索；同一封閉區包含多個編號時，標示邊界缺口，不自行以等分或 watershed 補出正式邊界。
- 多處出現的同一編號保留所有位置；未辨識編號不猜測。候選包含外環與內洞，所有幾何仍需人工覆核。
- 不覆寫既有 areas JSON，不匯入資料庫。候選數量不等於完成區域數。

## 限制

顏色擷取可能混入底圖標記、沿海與圖片邊緣可能缺少閉合線。報告必須列出未定位編號、合併編號、接觸圖片邊緣等狀況。
