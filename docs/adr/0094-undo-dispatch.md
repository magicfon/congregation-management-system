# ADR-0094：區域狀況可撤銷派錯的地圖

2026-10-29，已接受。

## 背景

使用者問區域狀況能不能收回地圖，情境是發現派錯人。原本只有使用中地圖與管理待辦的「收回／交回」，那代表這次使用結束：寫入完成時間、持有人留作歷史，Sheet D 欄保留這次派發日。派錯人時這些都不該留下。

## 決策

- 派發（區域狀況派發、核准申請）時，每張地圖在 `areas.dispatchUndo` 記下派發前的持有人、備註、派發日、完成日與最後活動時間，連同這次派發時間。
- 區域狀況點選使用中的地圖，管理員看到「派錯了？撤銷派發」，確認後還原成派發前的狀態：不寫完成時間、不改上次完成回報日，刪掉這次派發期間排定的傳道安排。
- Sheet「區域狀態」C 欄清空、D 欄改回派發前的日期，同步快照一併更新，cron 不會當成手動編輯。Sheet 寫入失敗時 DB 已撤銷，交由 cron 補推。
- 只有網站派發且仍是同一次派發才能撤銷；從 Sheet 匯入的分發或舊資料沒有撤銷紀錄，不顯示按鈕，照舊用收回。
- 若地圖是核准申請而來，申請紀錄維持「已核准」；個人區域 30 天提醒會比對派發時間，撤銷後不會再發。

## 取捨

不另做通知被派錯的人：派發本身沒有發 LINE 通知。
