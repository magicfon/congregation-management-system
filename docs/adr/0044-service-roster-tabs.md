# ADR-0044: 所有週次職務標籤

日期：2026-10-04
狀態：已接受

招待當值、替補招待與會堂招待員依使用者要求合併為「招待」標籤，表格維持三個工作欄並排。

使用者指定所有週次增加職務標籤，點選麥克風、音響等後向下列出各週安排人員，登入者另見「我的委派」。預設麥克風，A/B 同一標籤；其餘職務各一標籤，另保留全部工作與姓名篩選。未來優先與過去收合沿用 ADR-0042。

我的委派依私人身分 API 的已登入狀態顯示，不以是否已有排班 personId 決定入口；已登入但未對應排班名單時明示尚未對應，絕不退回所有人。身分失效後隱藏個人標籤並回職務瀏覽。職務與姓名同時篩選時，只列出所選工作確實由該人擔任的週次；沒有指定人員時保留空缺與停排說明。

依使用者要求，標籤採緊湊留白與 4px 間距，保留 18px 字級及至少 44px 點擊高度。職務標籤共用群組色相與亮暗主題文字色；我的委派用琥珀色，全部工作用中性色。選中狀態加深底色並以底線、邊框辨識。

2026-10-04：使用者要求所有週次改為連續表格，不再一週一張卡片。每列一週、每欄一項工作，保留職務標籤、姓名篩選、個人高亮、未來優先與過去收合。手機橫向捲動並固定日期欄；個人篩選僅保留該區間有委派的工作欄，其他週次的非本人格以破折號顯示，停排與備註保留。
