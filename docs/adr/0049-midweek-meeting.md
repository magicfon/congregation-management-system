# ADR-0049 週中聚會手冊匯入與編排

日期：2026-10-11
狀態：已接受（操作流程經使用者確認）

## 決策

從 https://www.jw.org/cmn-hant/多媒體圖書館/耶和華見證人聚會手冊/ 發現所有手冊期別與週次；分批、可續跑匯入，失敗保留待重試項目。每月檢查一次，重新取得來源並比對內容。只匯入節目摘要，不複製整篇研讀文章；排除拼音注音節點。

來源、草稿、發布快照分開儲存於現有 Setting 表的 midweek 命名空間。每週以來源網址識別，保留週開始日期；實際聚會日期預設該週五、時間 19:30，可修改。採第一班，主席、禱告、講者、學生、助手與主持人由管理員選啟用成員或手填姓名。選取姓名以文字快照保存，日後成員改名不追溯改寫已發布安排。

管理員可改標題與分鐘數、新增／刪除／移動節目、設定每項講評／轉場分鐘與黃綠更新標示；起始時間累加節目及轉場分鐘。初始唱詩禱告 5 分鐘、中間詩歌 4 分鐘、經文朗讀及學生節目講評 1 分鐘為可修改預設。

來源更新只修改來源副本，提示有新版；不自動套入已有草稿。重新建立草稿需明確確認。保存草稿不公開；發布將草稿複製為獨立公開快照。以版本比對避免兩位管理員互相覆蓋。公開 API 不回傳草稿或成員名單。

管理頁 /midweek/manage，公開頁沿用 /bulletin/midweek-meeting。維持 Word 白底、三色段落與紅色姓名；窄螢幕預設縮至完整寬度，可放大並水平捲動。每頁沿用 DashboardLayout。

每月來源檢查使用本站 Vercel cron 端點，不建立個人 Codex 提醒。每日台北 03:00 喚醒，按台北月份判斷是否需開始新的完整檢查；每批最多約 40 秒，未完成則隔日續跑，完成後當月不再重新抓取。全歷史匯入分批續跑避免部署平台逾時；管理員亦可手動檢查／續跑。月度完整檢查只在全部完成後記錄成功；網路或解析失敗重試三次，仍失敗列於管理頁，下次排程或手動檢查再重試，不能被當成空節目成功保存。

## 驗證

測試來源解析、跨月跨年日期、轉場計時、資料驗證、更新不覆蓋安排、版本衝突與公開快照隔離；以真實官方頁面抽驗及瀏覽器檢查版面。部署前 TypeScript 檢查，部署後登入保護及公開端點煙霧測試。
