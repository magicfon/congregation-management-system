# ADR-0042: 所有週次與個人委派瀏覽

日期：2026-10-04
狀態：已接受

使用者要求新增可一覽所有週別的頁面，方便提前查個人委派，並確認未來優先、可選姓名、過去安排另展開。

公開 `/bulletin/service-roster/all` 沿用唯讀排班 API、大字、分類色與專用圖示；本週頁新增「所有週次」入口。依完整日期排序，以台北今日與週結束日分出本週／未來及過去，避免週日與跨年判斷錯誤。姓名選項取自公開安排，以排班 personId 篩選，列出同週所有職務；停排週不算個人委派。沒有符合結果時明示尚無安排，不推測未排定週次。舊週保留在收合區，公開頁不載入管理資格或成員帳號資料。
