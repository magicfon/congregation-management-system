# ADR-0058：依弟兄／姊妹顯示個人委派

狀態：已接受（2026-10-17 使用者確認）

## 決策

成員 gender 為 brother、sister、unspecified，預設 unspecified，不推測既有成員性別。管理員於新增／編輯設定，API 驗證值。此欄位不改變登入權限或排班資料。

姊妹看板直接顯示節目內容，標題「我的委派」，不顯示分類頁籤或未連結服務人員提醒。直接開啟弟兄服務網址轉至節目頁。LINE 查詢同樣僅回傳節目委派與節目頁連結。弟兄及未設定保留兩類。

## 資料與驗證

採可重跑的新增欄位 SQL，既有資料使用未設定。個人委派共用查詢過濾弟兄服務，因此看板與 LINE 一致。測試三種設定、姊妹的學生／助手及過去紀錄、LINE 文字與頁籤顯示。

## 清單快速設定

使用者追加要求：管理員在清單直接點選弟兄／姊妹／未設定即儲存；儲存失敗保留原值並提示，手機與桌面皆提供。不傳送姓名或其他資料，避免覆蓋其他欄位。

## 批次儲存（取代清單即時寫入）

使用者要求全部設定後一次送出。前端以成員 ID 保存草稿及原值，搜尋不丟失草稿；按儲存才以單次請求提交。後端僅管理員可操作，驗證所有值並以交易分組更新，遇到刪除或原值變更整批拒絕，不覆蓋他人修改。失敗保留草稿，可取消全部變更。編輯視窗與派發設定維持原流程。

## 完成初次設定後精簡清單

2026-10-18 使用者確認屬性設定完成，移除清單快速設定與批次儲存介面。既有資料不變，後續透過成員編輯視窗調整。
