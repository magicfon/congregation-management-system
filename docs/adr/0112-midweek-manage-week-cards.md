# ADR-0112：週中編排頁每週一張卡片

2026-11-05，已接受。

## 背景

週中編排頁（`/midweek/manage`）連續列出多週（ADR-0099）。淺色模式下頁面底色、各窗格與節目單都接近白色，框線只有 10% 不透明度，每週之間只有一條細線，使用者反映「沒辦法一眼看出區塊」。提出三個方案（每週一張卡片／色條分區／卡片加合併工具列），使用者選擇「每週一張卡片」。

## 決策

- 每週包成一張卡片：`bg-mc-card`、較明顯的框線（`mc-text` 20%）與陰影、圓角。
- 卡片頂端是深藍色標題列（日期＋經文，白字），發布狀態改成彩色標籤：已發布綠色、草稿／已下架黃色、他人編輯中橘色。
- 卡片內的版次紀錄、發布狀態列、學生通知單窗格統一用淺灰底（`bg-mc-accent/40`），和白色卡片、白色節目單分開；節目單外加細框。
- 深色與淺色模式共用同一結構，只靠 `mc-*` 主題色切換；標題列與狀態標籤顏色固定，不受主題覆寫。
- 只改編排頁；公開節目表與嵌入頁不變。
