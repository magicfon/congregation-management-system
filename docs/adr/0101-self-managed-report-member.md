# ADR-0101：自主管理地圖的成員可回報未領取的地圖

2026-10-30，已接受。

## 背景

ADR-0100 讓一般成員不能回報未領取的地圖。使用者說曾湖是自主管理地圖，不受領取回報的限制（他是回報最多的傳道員）。

## 決策

- 成員新增「自主管理地圖」設定（`members.selfManagedReports`），管理員在成員頁編輯視窗勾選。欄位第一次建立時預設開給曾湖。
- 這類成員回報**未領取**的地圖：不擋、不必勾選確認，只寫入 Sheet 列與完成日，不改變分配。
- 回報**自己領取中**的地圖照常交回；回報**別人領取中**或已有回報待確認的地圖，照 ADR-0100 一般規則（交管理員確認、或擋下）。（使用者 2026-10-30 選擇）
- 未登入時以自填姓名對到成員，所以填「曾湖」也套用此設定。

## 取捨

做成成員設定而不是寫死姓名，日後有其他自主管理的人可直接勾選。
