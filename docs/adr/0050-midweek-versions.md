# ADR-0050：週中聚會版次與累積修改高亮

## 狀態

需求已由使用者逐題確認，已實作並通過版次切換及手機版面驗證。本文是 grill-with-docs 訪談的決策記錄；實作以此為準，取代訪談早期僅高亮姓名、不公開歷史等未採用方案。

本機實作使用既有 Setting 記錄保存 versions 與 versionDates；舊資料讀取時推導初始版次，首次寫入時以同一次樂觀鎖更新保存，無需直接批次修改正式資料。統一配色獨立保存，公開頁讀取時套用，已開啟頁面在切回焦點及每30秒更新配色。測試包含純差異規則、記憶體資料庫的並行發布與公開端點隔離，不連接正式資料庫。瀏覽器已驗證歷史內容切換、欄位分別高亮及手機單列操作。

## 名詞

- 週次：既有來源週次識別，一週的實際聚會日期可修改，版次仍歸屬原週次。
- 草稿：管理員編輯中的內容，不對外公開，也不增加正式版次。
- 發布版次：每週獨立遞增的內容快照，與既有資料寫入衝突檢查用 revision 分開。
- 欄位修改版次：某欄位最後一次內容變動所屬版次，用來決定累積底色。
- 統一配色：版號對應顏色的全站設定，並非儲存在各歷史快照中的固定色碼。
- 既有版次說明：由原始高亮及日期辨識的版號資訊，不代表擁有該版完整內容。

## 編輯與發布

1. 管理員直接修改草稿，編輯時即時預覽相對目前發布版的差異與下一版顏色。
2. 按「發布新版」才保存正式版次並對外公開。儲存草稿不增版。
3. 任何節目內容變動都可建立新版，包含僅變更節目名稱、日期或時長。
4. 內容完全沒變時提示「沒有變更」，不建立新版本。修改後又改回目前發布內容的欄位，不應視為本次修改。
5. 各週獨立編號。新節目首次發布為第1版，無自動高亮；第一次修改發布為第2版。
6. 新版更新日期自動使用發布當天的台北日期。
7. 管理員可將已保存版次退回為草稿，再發布新版；2026-10-16 使用者確認，詳見 ADR-0051。

## 自動高亮

- 累積保留各欄位的修改版次。第2版改主席、第3版改禱告人員，兩處分別保留第2、3版顏色。
- 同一欄再改時，顯示最新內容與最新修改版次顏色；舊內容由歷史版查看，不在紙面並排。
- 高亮涵蓋委派姓名、節目名稱、分鐘數、開始時間、聚會日期、每週閱讀經文與更新備註。
- 學生、助手姓名分別比較及標色；更換助手不會讓學生也換色。主席等單人委派同樣適用。
- 更改分鐘數時，該分鐘數及所有受影響的後續開始時間都標上本版顏色。以實際計算出的顯示時間比較，避免只比較原始時長而漏掉順延。
- 清空原本已填的人員，以本版底色顯示「待安排」。原先就未填的人員不應被誤判為取消委派。
- 刪除整個節目時，最新版直接移除，過往內容僅留於實際存在的歷史版本，不加刪除線佔用版面。

## 既有資料初始化

- 保留目前已發布內容及其原始更新底色。無更新色視為第1版，黃色對應第2版，綠色對應第3版。
- 以出現顏色所對應的最高版次判定目前版號，而非單純數顏色：黃綠皆有或只有綠色都屬第3版，下次發布為第4版。
- 灰、金、酒紅段落色帶，以及姓名本身的紅色文字，不是更新底色，不計入版次。
- 目前能取得的內容保存為對應版次；不得憑空產生第1、2版的舊內容。
- 保留來源中能確認的原表更新日期，例如原表明確記錄黃色9/17、綠色9/25。無法確認則標示「日期未記錄」，允許管理員補填，不以匯入或啟用日期冒充。
- 即使缺少舊稿，仍可顯示「黃色：第2版・日期未記錄」等顏色說明，但不能切換查看不存在的版本。
- 既有手動底色轉成對應版次的標記，保留啟用時外觀；後續依統一配色設定呈現。

## 統一配色

- 預設第2版黃色、第3版綠色、第4版淺藍、第5版淺紫、第6版淺橘；更高版次由系統補上不同淺色。
- 新發布時自動依版號取色，不要求每次選色。
- 管理員可修改統一配色設定，立即套用所有週次及可查看的歷史版本，包括原本的黃綠標記。
- 配色設定改動只影響顯示，不重寫歷史內容，不產生各週的新發布版次。

## 公布欄與權限

- 所有人可查閱已保存的公開歷史版次；進入時預設最新版。草稿不提供公開查閱。
- 維持精簡單列抬頭，在週次旁放版次選單，例如「第3版・10/15更新」。
- 顏色說明收合，點開才顯示，不常駐新增抬頭列。
- 管理員可編輯草稿、發布、調整統一配色、補填既有版次日期；不因新增歷史查閱而開放管理權限。
- 沿用原有下架的公開可見性邊界，不能透過歷史端點繞過下架。

## 實作驗證重點

- 重複發布、改回原值不增版；草稿儲存不影響公開版；兩名管理員同時發布不得重號或遺失版本。
- 學生／助手獨立差異、取消姓名、節目新增／刪除、順延時間、跨週獨立版號及累積標色。
- 無色／黃／綠／黃綠初始化、忽略段落色帶、缺失歷史內容及日期的誠實呈現。
- 配色全站即時套用但內容保持不變；訪客只能看已發布快照。
- 手機單列操作、歷史選單與收合圖例可用，保留既有雙指及滑鼠縮放操作。
