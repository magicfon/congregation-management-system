# ADR-0078：區域回報過渡期免登入

2026-10-24，已接受。修正 ADR-0076「只有登入成員可回報」。

使用者說明站內回報要取代 Google 表單，過渡期很多人尚未登入，所以未登入也要能用。

- GET／POST `/api/territory-reports` 不再要求登入。未登入時表單多一個「姓名」欄（最多 30 字），頁首提示登入可自動帶入。
- 未登入的區域清單只回傳區號與名稱，不揭露持有人與領取日；送出前只提示「使用中的地圖送出後會自動交回」。
- 交回規則與 Google 表單回報相同（ADR-0076），未登入也會交回使用中的地圖，與現行表單的效果一致。
- 姓名對到啟用中的成員：套用該成員的防呆（結束日不早於自己的領取日）、重複送出檢查，並留系統紀錄。對不到：只寫 Sheet，不建立成員、不留紀錄，避免任意姓名產生成員。
- 登入者仍以帳號姓名送出，body 帶的姓名不採用。
- 風險：與現行 Google 表單相同，任何人都能回報任一區並交回；過渡期結束後可改回限登入。
