# ADR-0019：編輯預覽、取消與平板操作

2026-09-28。使用者確認六項修正：取消語意、雲端儲存提示、雙指平移縮放、明確退點、無效邊界提示、平板工具列。

繪製頂點只更新預覽，不寫入可儲存文件；滿三點可顯示封閉預覽，只有完成區塊才加入文件並建立一筆復原紀錄。放棄按鈕與 Esc 都清除本次預覽，保留先前完成的修改。未完成或無效預覽不能儲存、匯入或切換模式；切換地圖先確認放棄預覽。雲端儲存成功並讀回核對後才顯示已儲存到雲端，手動指定號碼也納入未儲存判定。

繪製點以放開指標且未拖曳時加入；兩指接觸即取消單指手勢預覽並開始平移／縮放，全部離開後才恢復編輯。触控頂點先選取再拖曳，放大觸控範圍。新增退回上一點按鈕；點藍點只選取，刪除所選點須按按鈕。框選提供追加選取勾選，不依賴 Shift。

平板保留可收合更多工具，常用模式、復原、儲存及繪製完成／放棄按鈕常駐。無效預覽標红與錯誤原因，修正前不可完成。保留新舊區塊可重疊與既有雲端版本鎖。

驗證以真實 editor.js 的指標事件／按鈕入口重現取消失敗，加入繪製、取消、無效形狀、復原、儲存与多指競爭回歸。瀏覽器驗證工具列尺寸與可見性；實體平板觸控手感另需實機確認。
