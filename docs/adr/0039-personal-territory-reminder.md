# ADR-0039：個人區域 30 天回報提醒

狀態：已接受

使用者指定審核通過後固定 30 天，以 LINE 通知領取人回報。沿用現有同步 cron，完成同步且無錯誤後檢查，Vercel 每日台北中午執行，外部同步排程也可觸發。不新增第二條 Hobby cron。

以 reviewedAt 台北日期加 30 個日曆日，涵蓋現有已核准且仍在同一分發週期的個人區域。當前持有人及 dispatchedAt 必須符合原核准，完成回報日達領取日、已交回或分類取消則排除。只認正式完成回報，局部傳道進度不等於整張完成。

使用穩定 UUID 作通知 ID 與 LINE retry key，通知附 reminderRequestId，發送前再次驗證週期。通知開關、綁定 UID 與啟用狀態沿用既有流程。每筆申請只建立一則提醒，不每日重送；通知關閉時不排入。未發送前失效則取消。不自動交回地圖，也不改日期。
