# ADR-0106：區域回報限弟兄，領取個人區域的姊妹除外

2026-10-31，已接受。

## 背景

區域回報是弟兄傳道使用。使用者要求姊妹打開回報頁時顯示這是弟兄傳道用，除非姊妹有領取個人區域。

## 決策

- 已登入、性別為姊妹、目前沒有領取中的個人區域（`areas.personalTerritory`）的成員，回報頁只顯示說明「區域回報是弟兄傳道使用；姊妹若有領取個人區域，領取後即可在這裡回報。」，不顯示表單；送出 API 同樣拒絕。
- 有領取中個人區域的姊妹照常回報，規則同 ADR-0100。
- 管理員不受限；性別未設定視同不限；未登入無法判斷性別，照常顯示表單。

## 取捨

未登入的過渡期表單不擋，避免以姓名猜性別誤擋弟兄；正式改為 LINE 登入後自然生效。
