# ADR-0064：管理入口集中與全站導覽精簡

2026-10-23，已接受。使用者已確認全站審視列出的 12 項修改，要求以清楚簡單、管理入口容易找到為原則開始實作。延續既有操作流程，將相同目的地統一稱「我的看板」，管理員看板與側欄共用服務安排、週中編排、公告及成員四個管理入口；各管理頁保留回看板與公開內容的動線。

公布欄每頁只保留一個管理入口，分類切換收合；每週服務安排優先，正常同步細節收合，有衝突或錯誤則展開並在上方提示。手機控制至少 44px，閱讀頁編排入口顯示文字。公開圖檔與公開編輯器使用公開導覽，保留原公開草稿授權；編輯器增加留白並降低固定最小高度。使用中地圖保留兩個主要摘要，其餘篩選收合，簡化頭像裝飾。

這次選擇依工作分組及漸進展開，避免把所有工具同時鋪在畫面上。分發、收回、同步、登入與角色權限均沿用原規則；PDF、地圖、節目表內容配色與節目表字體不變。
