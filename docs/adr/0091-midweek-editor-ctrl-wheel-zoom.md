# ADR-0091：週中編排頁改用 Ctrl＋滾輪縮放

2026-10-29，已接受。部分取代 ADR-0049「編輯模式保留原控制列」。

使用者問編排頁為什麼還用＋－百分比按鈕縮放。原因是 2026-10-14 公布欄改手勢時，拖曳移動與鍵盤＋－０會與點欄位、打字衝突，編輯模式整套手勢關閉並保留按鈕列；ADR-0087 改 Ctrl＋滾輪時沒有回頭處理。

- 編排頁移除＋－、百分比與「適合寬度」按鈕。電腦在節目表內 Ctrl＋滾輪（含觸控板雙指）以游標為中心縮放，最小為適合寬度、最大 300%；手機用瀏覽器雙指縮放。
- 鍵盤＋－０只在公開頁啟用，避免打字時誤觸。
- 2026-10-29 補充：使用者反映編排頁放大後不能左右拖曳。編排頁改為可用滑鼠拖曳空白處移動；從欄位、按鈕上按下仍是點選與打字，不會拖動。
