# ADR-0141：會眾公告公布欄的無邊框嵌入版

2026-11-22，已接受。

## 背景

使用者要求「會眾公告」也比照公眾演講（ADR-0084）、週中聚會（ADR-0085）、傳道組別（ADR-0136）與區域回報（ADR-0138）提供嵌入頁，放進舊版 Google 協作平台的 iframe。

## 決策

- 網址 `/bulletin/announcements/embed`，加入嵌入頁白名單，`robots: noindex`。
- 內容與公布欄的會眾公告相同：公告列表依上傳時間新到舊，最新一則預設展開，點標題展開或收合 PDF。PDF 閱讀器沿用公布欄版本（含全螢幕按鈕、電腦 Ctrl＋滾輪縮放、手機雙指縮放）。
- 不包 `DashboardLayout`、無標頭，固定淺色，內容置中、最寬 4xl。
- 公告列表與 PDF 本來就公開讀取，iframe 內不需登入。嵌入版不查登入狀態，不顯示「新增公告」與「下架」；管理仍在本站公布欄進行。不顯示「原 Google 公告頁」連結（嵌入處就是該頁）。
- 不顯示外層捲軸（沿用 `bulletin-embed-no-scrollbar`）：展開或收合公告會改變高度，捲軸時有時無會讓寬度跳動。仍可滾輪或滑動捲動。
- 無資料庫、Sheet 同步或 LINE 變更。
