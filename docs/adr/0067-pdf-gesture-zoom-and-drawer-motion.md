# ADR-0067：PDF 改用手勢縮放，分類抽屜加入滑動動畫

2026-10-23，已接受。

## PDF 閱讀器縮放

使用者不要縮放介面，要求手機用雙指、電腦用滑鼠滾輪縮放。

- 移除 PDF 閱讀器工具列的「−」「100%」「＋」三顆按鈕，只保留頁數與全螢幕。
- 手機沿用既有的雙指縮放與拖移。電腦（`pointer: fine`）在閱讀區內轉動滾輪即縮放，以游標位置為中心，範圍是 100%–500%；拖曳可以移動畫面，捲軸仍可使用。Ctrl＋滾輪與觸控板雙指縮放交給瀏覽器處理。
- 縮放倍率仍會隨閱讀位置記住；「回到開頭」會同時重設縮放。說明文字改為「手機雙指縮放 · 電腦滾輪縮放、拖曳移動 · 自動記住閱讀位置」。
- 這與週中節目表（2026-10-14）的「表內滾輪縮放與拖曳」一致。取捨是電腦版在閱讀區內不能用滾輪翻頁，改用拖曳或捲軸。

## 分類抽屜動畫

延續 ADR-0066 的漢堡選單：開啟時抽屜由右側滑入、背景淡入（220ms），關閉時滑出、淡出（180ms）後才移除。系統設定減少動態時不播放動畫，直接開關。
