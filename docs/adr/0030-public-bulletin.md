# ADR-0030: 公開公布欄沿用 Google 內容

日期：2026-09-30
狀態：已接受

## 需求確認

使用者要求另製適合手機及平板的公布欄，參考 https://sites.google.com/view/jwnanzhi/，可重新設計。問答確認：免登入公開、先用相同分類、繼續在 Google 更新資料。

`grill-with-docs` 已讀取；它引用的 `/grilling` 和 `/domain-modeling` 技能在專案與本機技能目錄皆不存在。以直接問答確認操作流程並記錄本文件與 CONTEXT.md，保留上述缺失供後續修復。

## 決策

- `/bulletin` 為公開首頁，七個分類各有可分享網址；首頁採深色卡片，分類頁提供 Google 嵌入與明確的原文件入口。
- 沿用原頁已公開連結的試算表、Apps Script 及 Google Form。Google 內容由訪客瀏覽器直接載入，不以伺服器憑證讀取，不更改 Google 分享權限。
- 服務安排保留輪值表與組織表；集合地點保留 Apps Script 與表格；週中節目表保留 Apps Script 與文件連結。
- 會眾公告原頁無內容來源，先顯示原公告頁入口，不建立假公告或複製過期內容。
- 使用 DashboardLayout 的公開版型提供公布欄導覽與登入入口，訪客不呼叫 `/api/me`。管理側欄、登入頁皆提供公布欄入口；既有受保護頁面與 matcher 不變。
- 無資料庫變更、Sheet 同步變更或 LINE 群發。更新內容流程維持 Google 原有流程。

## 限制與驗證

Google 嵌入是否可看由原始分享權限與第三方服務決定，保留原文件入口作為替代。本站不宣稱內容載入完成或自行推算更新時間。驗證 TypeScript、公開路由 200、既有登入保護，以及手機與平板版面。
