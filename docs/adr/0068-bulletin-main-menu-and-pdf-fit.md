# ADR-0068：公布欄主選單與 PDF 自適應閱讀區

2026-10-23，已接受；調整 ADR-0066。

## 主選單

使用者要求把公布欄標頭的「我的看板」按鈕換成漢堡按鈕，「我的看板」放進主選單。

- 標頭右上依序為外觀控制和 ☰（無障礙名稱為「主選單」），不再直接顯示「我的看板／登入」按鈕。
- 選單由右側滑出（沿用 ADR-0067 的動畫）。第一列是「我的看板」，訪客則為「登入」並帶回目前頁面；讀取登入狀態失敗時顯示「重試登入狀態」。下方是「公布欄分類」七項，所在分類打勾。
- 分類頁不再另放 ☰，避免同一畫面出現兩個漢堡。分類切換統一由標頭主選單進入。週中聚會閱讀頁沿用原本無標頭的版面。

## PDF 自適應

使用者反映 PDF 內容四周空白太多，希望內容自適應視窗大小。

- 每頁先以低解析度繪製一次，找出非白色內容範圍，留 1% 邊距後裁掉四周空白。左右邊界與第一頁取聯集，讓各頁字級一致；上下邊界各頁分別裁切。內容極少（面積小於整頁 0.2%）或偵測失敗時不裁切。
- 預設把整頁放進閱讀區，寬和高取較小的縮放比例，並置中顯示。之後再套用使用者的雙指或滾輪縮放；全螢幕時閱讀區變大，頁面隨之放大。
- 裁切只影響顯示。下載、原文件連結和版本判斷都使用原始 PDF。
