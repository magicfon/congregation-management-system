# ADR-0032: 公布欄快速 PDF 閱讀器

日期：2026-10-01
狀態：已接受

## 需求與操作

使用者同意將節目表、組別、服務安排改成可双指縮放的閱讀方式，並要求讀取目標一秒內。Google 仍為編輯來源。直接匯出實測約 1.8～4.4 秒，不能放在每次閱讀的等待路徑。

## 決策

2026-10-01 更新時間與接續閱讀：使用者選擇這兩項功能。Google Drive REST files.get 只讀 modifiedTime，沿用既有 REST token，不增加 OAuth 權限；查詢與 PDF 匯出平行，三秒內無結果時不阻擋 PDF，改顯示成功匯出的「同步時間」。時間與 PDF 同一份 ISR 回應，避免顯示較新的時間卻讀到舊文件。位置依文件 ID 存 localStorage，包含版本、頁碼、頁內比例、縮放及水平位置；不同螢幕尺寸仍按頁定位。新版本丟棄舊位置，儲存失敗不影響閱讀。無 modifiedTime 時以排除匯出日期及 PDF ID 的內容雜湊辨識版本；保守地在內容不同時回到開頭。

2026-10-01 外觀補充：使用者要求亮／暗主題、預設依裝置。公開版型提供三個外觀按鈕，裝置設定以 CSS media query 即時跟隨，手動偏好存 localStorage 並同步其他分頁。主題 token 僅作用於公布欄及其全螢幕閱讀器，PDF 紙張與文件原色保留。

2026-10-01 補充：使用者要求以垂直連續頁面取代翻頁按鈕。頁面依序保留位置，接近視窗才繪製，離開視窗釋放畫布；縮放與全螢幕作用於整份文件。

- 固定來源白名單匯出 PDF，建置時預產生公開 API 回應，以 Next ISR 每 300 秒背景重新驗證；更新失敗保留先前成功內容。五分鐘為尚未另指定時的速度優先預設，並非即時同步保證。
- PDF.js 在本站呈現單頁，只載入所需頁面；縮放重新渲染 PDF 向量文字，保留照片原解析度。提供雙指縮放、拖曳、比例按鈕、翻頁、全螢幕及原文件替代。
- 首頁預熱閱讀器，指向分類時預抓該分類 PDF；不要求手機下載所有七份文件。第一頁優先，後續翻頁沿用已載入文件。
- Google Apps Script 不是 PDF 來源，保留在收合的補充資訊內。Google Form 維持原有互動入口。
- 一秒是第一頁可讀目標，須測量實際內容繪製，不以骨架或 API 回應時間冒充；網速與裝置差異不保證每次達成。
- 不使用 Google OAuth、資料庫或 LINE 通知。

## 驗證

檢查 PDF 白名單、非 PDF 拒絕、失敗不緩存、型別、正式建置、快取回應與實際閱讀、翻頁縮放及手機版面。
