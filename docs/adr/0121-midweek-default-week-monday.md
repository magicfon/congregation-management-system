# ADR-0121：週中節目表週一切換到本週

2026-11-09，已接受。修正 ADR-0049／ADR-0085 的預設週次。

## 背景

公開週中節目表與嵌入頁預設選「聚會日期 ≥ 今天減 3 天」的第一週。聚會日期是週五（手冊週一＋4），週一減 3 天剛好等於上週五，所以週一仍停在上一週，週二才跳新週次。使用者週一發現節目表沒有切換。

## 決策

- 預設週次改為「聚會日期 ≥ 台北本週一」的第一週，與週中編排區分本週／過去週的 `weekMonday` 一致。週一起就顯示本週聚會；週六、週日仍顯示本週（剛結束）的聚會。
- 本週之後都沒有發布的節目時，照舊顯示最後一週；`?week=` 指定週次的規則不變。
