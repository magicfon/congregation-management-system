# ADR-0055：儀錶板與 LINE 個人委派

日期：2026-10-17
狀態：已接受

## 決策

使用者確認儀錶板集中顯示本人的服務安排及週中聚會節目（含主席、負責人／學生、助手），預設顯示台北本週與所有未來已發布安排，過去安排另行展開。使用者補充委派分為「弟兄服務」與「節目委派」兩頁（`/dashboard/assignments/service`、`/dashboard/assignments/program`），儀錶板提供兩頁入口並預設弟兄服務。招待、麥克風、講台、音響及影像歸弟兄服務；主席、朗讀（含守望台）及週中各節目角色歸節目委派。兩頁皆含本週起與可展開的過去紀錄。LINE 分兩類條列並各附對應頁連結。

LINE「我的委派」改為訊息動作，在私人聊天室按日期條列相同資料，附儀錶板連結；超長清單明示省略筆數，完整內容於網站查看。

服務安排沿用成員 ID 與 ServicePerson 連結，停排週不列。週中只讀目前 published 快照，不讀草稿或最高歷史版；現有節目只存姓名，因此僅以啟用、未刪除成員中的唯一完整姓名（去除前後空白）辨識，同名不自動歸屬並提示。週中以台北週一為週界，服務安排沿用起迄日。原傳道行程及持有地圖維持儀錶板既有區段。

網站與 LINE 共用查詢，身分分別取登入者及已綁定 LINE UID；未配對／停用維持既有拒絕流程。不新增主動推播。LINE 選單升版避免重用舊網址動作。
