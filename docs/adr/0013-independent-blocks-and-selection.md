# ADR-0013：獨立重疊區塊及平滑後保留選取

2026-09-22，使用者更正：外層不可因內部小區塊被挖空；區塊可重疊，刪除只移除被選區塊。另要求平滑後繼續選取平滑後的頂點。

## 決定

取代 ADR-0012 的虛擬內部區塊。舊草稿的內環轉成獨立候選，外層只保留外環；使用確定且不衝突的 ID。轉換只在缺少 independent-blocks-v1 模型標記的舊文件執行，已轉換文件不重建刪除的候選；模型標記隨雲端草稿保存。此後真正的內洞仍可由 polygon 內環表示，不再自動變成候選。

載入時轉換舊資料，有幾何變更則標記尚未儲存，使用者按儲存才持久化。原始圖片不變。小面積區塊後繪製，確保可選取；各區塊可正常補線、編輯、平滑或刪除。不同候選間允許重疊，自交、同候選部件及內洞幾何有效性檢查保留。

批次幾何操作回傳新文件及更新後選取；平滑保留原選取中存活頂點，未選點不納入。失敗保留原選取；刪除後清除選取。選取為暫態 UI 狀態，不寫入雲端。

## 驗證

轉換冪等、58 號外層完整且小區塊獨立、刪除小區塊外層不變、儲存後不復生；跨區塊重疊可操作，自交仍拒絕。部分段與跨首尾平滑的選取索引正確，連續平滑及平滑後直接批次刪除。
