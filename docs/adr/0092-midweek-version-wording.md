# ADR-0092：週中版次畫面白話化

2026-10-29，已接受。延續 ADR-0053、0054、0057，版次規則不變。

## 背景

使用者覺得編排頁的版次管理太複雜。提出「版次只往前走、只能撤回最新版」的簡化方案後，使用者選擇保留現有規則（退回原版號、保留後續版本、進版前確認刪除），只整理畫面。

## 決策

- 主畫面狀態列直接說明狀態：「公開中：第N版／已下架／尚未公開」，加上「草稿是第B版」（退回後尚未公開時）、「有未儲存的修改」或「有修改尚未發布」。
- 草稿已改且有較高版本時，發布前就在狀態列以黃字提示「發布會成為第B+1版，並刪除舊的第X～Y版」，不讓確認視窗成為第一次得知。
- 發布按鈕依情況顯示「發布第N版」「改回公開第B版」（退回未修改；下架時為「公開第B版」）或停用的「已發布」；沒有未儲存修改時「儲存草稿」停用。
- 用語改白話：「退回此版」改「用這版當草稿」、「唯讀」改「只能看」、「草稿基準」改「草稿來自第B版」（與公開版相同時不顯示）、「刪除後續版本」改「刪除第X～Y版」並寫明範圍；不能刪時提示先按「改回公開第B版」。
- 確認視窗與完成訊息縮短，改用同一套說法。後端、資料格式、學生通知單（ADR-0090）不變。

## 驗證

TypeScript 檢查與 `npm run check:midweek` 既有測試通過；行為不變，僅前端文字與按鈕啟用條件調整。
