# ADR-0027：交接提醒、時間軸、預排調整與局部橡皮擦

狀態：Accepted，2026-09-30

使用者同意四項改善：儀錶板交接待辦、依日期查看單次傳道進度、修改未開始的預排、擦除自己的局部筆跡。

- 待交接由目前輪次計算：有已提交紀錄且無 active 任務。顯示最後提交者與最近預排；啟用下一位或交回地圖後提醒消失。只列本人管理的地圖，不發送外部通知。
- 時間軸依提交時間排列，可查看單次笔跡、姓名、日期與備註，過往輪次仍可唯讀查看。預排／進行中／取消與已提交時間軸分開。
- 管理者或 admin 可修改 planned 的日期與傳道者，沿用版本檢查、有效成員及同日同人重複檢查。active／submitted／cancelled 不可修改。
- 橡皮擦將未提交筆跡切成保留下來的片段；座標仍使用既有正規化格式，不改圖檔、其他人或已提交的筆跡。每次手勢可復原，雙指縮放會放棄未完成擦除。
