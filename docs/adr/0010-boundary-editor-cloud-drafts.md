# ADR-0010：分區修正編輯器與雲端草稿

日期：2026-09-20
狀態：已確認需求，實作

## 需求與操作

使用者確認加入補線、調整頂點、儲存修正，並明確選擇跨裝置共用的雲端儲存。

- 選取色塊 → 補線（沿缺口逐點畫線）→ 完成切割；新區塊依編號位置重新配對。
- 選取色塊 → 調整頂點 → 拖曳控制點，支援復原／重做。
- 2026-09-22 使用者確認：調整頂點模式可點選頂點，再按「刪除頂點」或 Delete。刪除後連接前後頂點，每環至少保留三個頂點；拒絕交叉、內洞外移與重疊，沿用復原與雲端儲存。
- 管理員登入後明確按「儲存到雲端」；其他裝置開啟時載入同一張圖的最新草稿。

## 決策

- 沿用 ADR-0009 的像素 JSON，正式區域資料不變。獨立 Neon `map_boundary_drafts` 表保存每張圖的草稿、版本、修改者及修改時間。
- GET/PUT API 均要求有效管理員身分。PUT 比對 expectedVersion，衝突回 409，不自動覆蓋。
- 本機備份與匯出 JSON 提供失敗復原；本機資料不冒充雲端已儲存。載入雲端前若有未存變更，要求明確選擇。
- 補線以 2 原圖像素寬的障礙帶裁切選取區塊，保留多部件與內洞。未真正切開時拒絕操作；新候選仍標記待覆核。
- 編輯既有頂點前檢查自交與內洞關係；重算配對與摘要。不可只改畫面而未改 JSON。
- 編輯頁位於 `/map/boundary-editor`，包 DashboardLayout。舊草稿預覽提供入口，靜態工具可編輯／備份，但同源 Next.js 服務與登入才可雲端儲存。

## 驗證

幾何切割涵蓋凹多邊形與內洞；拒絕不相交／無法切開、自交、超出圖片及不相符原圖的匯入資料；版本衝突不丟失本機編輯。部署須建立獨立草稿表。
