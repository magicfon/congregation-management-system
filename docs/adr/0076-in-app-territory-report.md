# ADR-0076：站內區域回報

2026-10-23，已接受。延伸 ADR-0003（Form 回報匯入）。

使用者希望區域回報不必再透過 Google 表單，改在站內填寫。

## 決策

- 公布欄「區域回報」分類改顯示站內回報表單；未登入者顯示登入按鈕。Google 表單過渡期並存，頁內保留連結。
- 只有登入且啟用的成員可回報，姓名用帳號姓名。區域下拉預設列出自己領取中的地圖，選「其他」才出現區號（1–213）輸入欄，並顯示該區目前持有人。
- 欄位沿用表單：傳道時段（下拉：星期六早上、星期日早上、星期三早上、星期一早上、星期三晚上，或自填「其他」）、區域號碼、開始日、結束日、備註。時段選項依 Sheet 歷史常用值整理。
- **與 Sheet 完全同步**：每筆回報以表單相同欄位順序 append 到 Sheet「傳道區域回報」A:G（USER_ENTERED，時間戳記為台北時間），讓「區域狀態」E/F/G 公式照常計算。DB 寫入（Report 紀錄、交回）與 Sheet append 在同一個 transaction 內，append 失敗則整筆取消。
- **回報即交回**：該區使用中，且結束日（台北日曆日）不早於該輪領取日時，completedAt 設為送出時間，Sheet「區域狀態」清 C 留 D 並更新快照（同 collect）。同時把 lastReportedCompletedAt 推進到結束日；之後的同步以 Sheet E 欄為準。結束日早於他人地圖的領取日時，視為上一輪的遲交回報，只寫紀錄不交回。
- **防呆**：日期須為有效日期，開始日 ≤ 結束日 ≤ 今天（台北）；回報自己領取中的地圖時，結束日不得早於領取日。10 分鐘內同一人、同一區、相同內容的回報視為重複，拒絕。
- **既有不一致檢查**：看板「管理待辦」新增「回報未交回」分類，列出「使用中，但最後回報完成日（台北日）晚於領取日」的地圖。回報日等於領取日不列入，因可能是前一位持有人當天的回報。只列出，由管理員逐張按交回（沿用 collect）。

## 後果

- 現有 cron 會讀到站內寫入的列，因地圖已交回而略過，不重複處理。
- 交回需要 213 區完整的同步快照，快照不完整時暫停送出，與 ADR-0025 整張交回一致。
