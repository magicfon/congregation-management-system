# ADR-0034：成員刪除與歷史保留

日期：2026-10-01；狀態：已接受

使用者要求將清單停用按鈕換成刪除，刪除後不封鎖 LINE 登入。

採 deletedAt 軟刪除，清單及編輯 API 排除已刪除者；保留姓名與歷史關聯，不執行 cascade delete。解除 LINE 綁定、釋放 email，既有工作階段失去原成員權限。LINE 下次登入沿用未連結身分流程，登記待管理員連結，不封鎖 UID。

僅管理員可刪除，不得刪除自己；持有地圖或尚有未完成傳道／未來負責行程需先交接。待審申請與待發通知取消。檢查及修改在 Serializable 交易內完成。介面提供一次確認，失敗保留清單項目。
