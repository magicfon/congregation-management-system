# ADR-0073：人員資格總表

2026-10-23，已接受；2026-10-24 由 ADR-0075 取代。

使用者覺得人員資格只能從下拉選單一次看一個人，不好管理，要求加一張總表。

- 管理服務安排頁的「人員資格」區塊最上方加一張「人員 × 職務」總表：每列一人，每欄一個職務（順序同 `serviceRoles`），具備資格打勾。
- 欄標題下方顯示該職務「可安排且已對應成員」的人數，方便看哪個職務人手不足。
- 排序：可安排的人在前，停用的其次，待對應的最後，同組依姓名排序。停用與待對應的列文字較淡並加標記。
- 總表只供檢視，不在表上直接改資格。點名字會帶進下方既有的編輯表單（同時捲到表單），在表單儲存，避免誤觸就寫入資料庫。
- 手機上表格在區塊內左右捲動，姓名欄與標題列固定，頁面本身不會橫向捲動。
