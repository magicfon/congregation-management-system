# ADR-0107：地圖分配點選區域收合側欄，地圖資訊列出最近三次回報

2026-11-04，已接受。

## 背景

使用者要求在地圖分配頁點選區域號碼時，自動把「設定」與「派發清單」收合起來；地圖資訊另外寫出前三次回報的時間與人員。原本點選只會展開地圖資訊，其他面板維持原狀，明細常被擠到看不到。

## 決策

- 點地圖區塊或用「區域號碼」跳轉時：展開地圖資訊，收合設定與派發／申請清單。之後手動展開不受影響，清單內容也不會清掉。
- 地圖資訊在「距上次完成回報」下方加「最近回報」：每張地圖列出最近三次回報的結束日與回報人，由新到舊。
- 資料來源是 Sheet「傳道區域回報」（站內回報與 Google 表單都寫在這裡）：D 欄區號、F 欄結束日（沒有就用 A 欄時間戳記的日期）、B 欄姓名。同人同日的重複送出只算一次。
- 新增 `GET /api/area-status/history?nos=…`，登入即可讀，伺服器快取一分鐘內讀到的回報表；點選區塊時另外載入，不拖慢地圖本身。

## 取捨

資料庫沒有完整回報歷史（`lastReportedCompletedAt` 只存最後一次），所以直接讀 Sheet。Sheet 讀不到時只在該欄顯示「暫時無法讀取回報紀錄」，不影響其他操作。
