# ADR-0032：LINE 圖文選單與配對完成通知

日期：2026-10-01
狀態：Accepted

使用者同意先做底部圖文選單及配對完成通知。採四格「我的地圖／本週行程／待交接／公布欄」，前三格發送既有查詢指令，第四格開公開 /bulletin；不新增聊天分發操作。未配對者點查詢仍進待確認流程。

- 選單採程式繪製 PNG，固定版本與點擊座標，後台提供預覽。只有管理員可讀取發布狀態及發布；以目前預設選單 ID 避免覆蓋剛被別人改動的設定。
- 發布依序建立選單、上傳圖片、設為預設。設定表保存本系統選單 ID 以供重試；短期排他鎖避免並行發布。上傳完成前不變更預設，不刪除原選單或個人專用選單。
- 新 UID 確認連結與既有 LINE 移動配對成功時，在同一交易中加入完成通知；失敗交易不發訊息。交易後嘗試傳送，傳送失败不回滾配對。
- 通知含配對成功、成員姓名及網站入口，沿用個人通知開關、固定 retry key、UID 重新核對與既有過期規則。只通知本次配對，不補發歷史配對。
- 移動舊 LINE 綁定時，只要來源使用者或目標成員已關閉通知，配對後仍維持關閉，不因重新配對重新啟用通知。
- 通知顯示「LINE 已接受／待重試／未發送」，不宣稱對方已讀。圖文選單的 LINE 實際發布與手機可見性另行驗證。
