# ADR-0145：公眾演講週一 LINE 提醒

2026-11-24，已接受。

## 背景

使用者要求管理員可以開啟每週一提醒特定人員，週末聚會的公眾演講講者是誰。公眾演講資料目前只在公布欄引用的 Google 試算表「楠梓會衆 公衆演講秩序表」，系統沒有結構化資料。

## 決策

- 設定存在 `settings` 表 `public_talk_reminder`（JSON：enabled、memberIds、lastRun），不改資料庫結構。
- 我的看板「管理工具」新增「公眾演講週一提醒」卡片：開關、從在籍成員挑收件人（標示未連結 LINE 或已關閉通知者收不到）、預覽本週內容、顯示上次排程。改動立即儲存。
- 排程用 Vercel Cron `0 1 * * 1`（UTC 週一 01:00＝台北 09:00；Hobby 方案實際觸發在該小時內），端點 `/api/cron/public-talk-reminder`，Bearer `CRON_SECRET`。
- 內容即時讀公開試算表 CSV（`export?format=csv&gid=0`，免金鑰）。表上日期只有月/日：第一筆取離本週最近的年份，之後依「2027年」分隔列與月份倒退推算跨年。
- 取本週（台北時間週一～週日）的演講列，列出日期、講題（編號為數字才顯示）、講者（空白寫「尚未安排」）。本週沒有演講列時，改用落在本週、整列只有文字的活動列（如「2027年3月7日(天)分區監督 分區大會」，去掉日期前綴）。都沒有就不發。
- 透過既有 `line_notifications` 佇列發送，id 由「週一日期＋成員」雜湊而成，重跑同一週不會重複；只發給在籍、已連結 LINE 且未關閉 LINE 通知的成員，未送達的由既有 15 分鐘同步排程重試，23 小時後過期。

## 後果

- 試算表格式大改（日期欄位置、分隔列寫法）時需調整解析；卡片預覽可先看出問題。
- 主席、守望台、誦讀等欄位目前不放進提醒。
