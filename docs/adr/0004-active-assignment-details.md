# ADR-0004: 使用中地圖以人員展開逐張明細

日期：2026-09-20
狀態：已接受

## 背景

地圖號與天數擠在小標籤中，難以看出各張地圖已領取多久；手機版的人員詳情位於整份名單下方，也不易找到。

## 決策

- 預設收合人員明細，點選人員後就地展開，再點一次收合；一次展開一人。
- 人員摘要保留張數、地區與領取狀況，展開後使用「地圖／已領取」兩欄，一張地圖一列，保留既有圖檔連結。
- 依領取完整天數由大到小排序，不按地區拆開；未記錄日期的地圖排最後，明確顯示「分發日未記錄」。
- 沿用 dispatchedAt 計算領取天數，30–59 天黃色、60 天以上紅色，文字與顏色共同表達狀態。
- 明細遵循目前搜尋與篩選，標明顯示的是篩選結果。

## 後果

桌面與手機使用相同展開流程，不再需要獨立側邊詳情；不變更資料庫、同步或收回語意。
