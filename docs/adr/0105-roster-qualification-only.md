# ADR-0105: 服務安排只看資格，沒有「不可安排」

日期：2026-10-31
狀態：已接受

使用者表示服務安排「只有資格，沒有所謂不可安排」。起因是同步匯入時，Schedule 排的劉博被判為「已停用」而被擋下；這個狀態來自人員資格的「可安排」勾選，或連結成員被停用、刪除，使用者並不知道有這層設定。

- 取消「可安排」：人員資格名單上的人一律可排，是否能排某職務只看資格（含 ADR-0104 的免資格職務）。修正 ADR-0081 中「連了成員的人看可安排與成員是否仍啟用」的規則。
- 進階設定不再顯示「可安排」勾選，名單不再標「停用」。資料庫的 enabled 欄位保留但不再使用。
- 連結成員被停用或刪除時，名單上的人照樣可排；不想再排就移除他的資格。
- 成員連結仍只用於「我的委派」高亮與看板。
