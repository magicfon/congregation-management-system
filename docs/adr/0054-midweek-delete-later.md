# ADR-0054：獨立刪除後續版本與直接編輯

日期：2026-10-17
狀態：已接受（使用者要求增加獨立刪除按鈕，並取消預覽模式）

## 決策

- 延續 ADR-0053 的退回原版號與進版前刪除確認，另在草稿操作列加入「刪除後續版本」。以草稿基準版為界，顯示保留版號及刪除範圍，確認後才刪除較高版的快照與補填日期。
- 單獨刪除不進版、不發布，不變更已保存草稿與目前公開內容；瀏覽器中尚未儲存的修改也保留。沒有後續版本時不顯示按鈕。
- 若目前公開版也在待刪範圍，先提示發布退回的版本，再開放單獨刪除，避免刪除目前公開快照。下架時可刪除，並使保留的發布版號指標回到草稿基準版，維持下架。
- 後端要求明確刪除確認，沿用管理員權限及樂觀鎖；過期或並行操作不可誤刪別人的新版本。
- 取消預覽模式、預覽按鈕及退回後進入預覽的行為。草稿直接在節目表編輯；歷史版仍僅查看，按退回後立即可編輯。

## 驗證

使用記憶體資料庫檢查獨立刪除的範圍、日期清理、不進版、不改草稿與公開內容、拒絕刪除目前公開版、確認旗標、過期／並行操作、下架後操作與再次進版；執行週中既有檢查及 TypeScript 檢查。
