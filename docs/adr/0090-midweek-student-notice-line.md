# ADR-0090：週中學生練習通知單透過 LINE 發送

2026-10-29，已接受。

使用者要求週中委派公布後，透過 LINE 把 S-89-CH「傳道與生活聚會學生練習通知」發給學生。

- 通知單以 LINE Flex 卡片呈現，不產生圖片：標題、姓名、助手、日期（含星期）、節目名稱、受訓班別（☑／☐ 第一～三班）、學生注意與 S-89-CH 字樣，底部按鈕連到該週節目表。系統沒有班別欄位，一律勾第一班。
- 學生節目沿用匯入時的角色：「學生」（經文朗讀、學生演講）與「學生/助手」（示範）。
- 使用者不要網頁上的預覽按鈕（2026-10-29 已移除），改為在官方帳號聊天室輸入「通知單樣式」：已綁定的管理員會收到一張標「樣式預覽」的卡片，內容取最近一週已發布節目的第一位學生，沒有則用範例資料；其他人照一般選單回覆。`src/lib/student-notice.ts` 保留卡片組法供正式發送使用。
- 正式發送（使用者 2026-10-29 照建議確認）：
  - 發布後不自動送。已發布的週次，在編排頁儲存／發布列下方出現「學生練習通知單（LINE）」，按「發送學生通知單」先列名單：將發送、將發送更新、將通知取消、無法用 LINE 發送（請自行轉交）、已發送沒有變動；按「確認發送 N 則」才推播。只讀已發布版本，不讀草稿。
  - 助手也收到同一張卡片（姓名欄仍是學生），卡片上方註明「你擔任這個節目的助手」。
  - 姓名以啟用成員的完整姓名唯一對應（同 ADR-0055）；找不到、姓名重複、未綁定 LINE 或關閉 LINE 通知的人列為無法發送，由管理員自行轉交。
  - 每週發送紀錄存在 Setting `midweek:student-notices:<週次 id>`，以「節目 id＋學生／助手」為鍵，記成員與內容指紋（姓名、助手、日期、節目、班別）。再按一次只發新增或內容有變的人，同一人內容變動的卡片標「更新」；被換掉或節目移除的人收到一則文字「學生練習取消」。同一節目只是學生／助手互換的人不發取消，改發更新。發送失敗的不記錄，下次再按會重送。
  - 直接推播，不排入通知佇列（佇列 23 小時過期，且是給地圖提醒用）。
- 2026-10-29 補充：使用者第一次正式發送後反映名單文字列表難讀。名單改為依節目分卡，每張卡列節目名稱與學生、助手兩列，姓名旁以色塊標狀態（將發送／將發送更新／已發送／需自行轉交），上方一行摘要數量；取消另列。有人需自行轉交時，該節目卡提供「複製通知文字（轉交用）」，複製純文字版通知單。節目名稱去掉節目表用的方括號（卡片與名單皆同），比對舊紀錄時也忽略方括號，避免已發送者被誤判為變動。
- 2026-10-29 補充：使用者要求轉交用通知改成圖片。「複製通知文字」改為每位需轉交者一個「某某的通知單圖片」按鈕，於瀏覽器以 canvas 依紙本 S-89-CH 版面畫成 PNG（裝置字型，不經伺服器、不需伺服器字型），手機支援時直接開分享選單（可選 LINE），否則下載圖片。純文字版移除。網站產生通知單不使用 AI，不耗 token。
