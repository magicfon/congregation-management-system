# ADR-0090：週中學生練習通知單透過 LINE 發送（第一步：樣式預覽）

2026-10-29，進行中。

使用者要求週中委派公布後，透過 LINE 把 S-89-CH「傳道與生活聚會學生練習通知」發給學生。

- 通知單以 LINE Flex 卡片呈現，不產生圖片：標題、姓名、助手、日期（含星期）、節目名稱、受訓班別（☑／☐ 第一～三班）、學生注意與 S-89-CH 字樣，底部按鈕連到該週節目表。系統沒有班別欄位，一律勾第一班。
- 學生節目沿用匯入時的角色：「學生」（經文朗讀、學生演講）與「學生/助手」（示範）。
- 第一步先做樣式預覽：週中編排頁「更多管理」→「傳通知單樣式給我」，以該週（已發布優先，否則草稿）第一個有學生的節目，只推播給按鈕的管理員本人，卡片標「樣式預覽」。沒有學生時用範例資料。直接推播，不排入通知佇列。
- 正式發送流程（觸發時機、助手、未綁定者、改版重發）待使用者確認後另行補充。
