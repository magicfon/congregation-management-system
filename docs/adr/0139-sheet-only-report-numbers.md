# ADR-0139：尚未建立地圖的 214、215 號可以回報

2026-11-22，已接受。

## 背景

使用者要求先開放區域回報填入 214、215 號，即使系統還沒有這兩張地圖。

## 決策

- 區域回報接受 1–213 與 214、215（`SHEET_ONLY_SHEET_NOS`）。系統若已建立該號地圖，照一般規則處理；還沒建立時：
  - 只在 Sheet「傳道區域回報」寫一列，格式同其他回報。
  - 不建系統回報紀錄、不建待辦、不交回，「區域狀態」（只有 1–213 列）與同步快照不變。
  - 確認畫面顯示「尚未建立地圖：只寫入回報紀錄」，不需勾選確認；可跟其他區一起回報。
  - 不收拒絕拜訪地址（沒有地圖可掛），表單不顯示該欄，備註說明改為可寫在備註。
- 所有可回報的人都能填（含免登入的嵌入頁），不限管理員。
- 每 15 分鐘同步匯入回報時，這兩個號碼略過、不列為「找不到區域」錯誤。
- 日後正式建立 214、215 號地圖時，需另外擴充「區域狀態」與 213 區完整性檢查，屆時再定。
