# ADR-0112：週中編排可唯讀閱覽過去週次

2026-11-05，已接受。

## 背景

週中編排頁（`/midweek/manage`）從 ADR-0099 起只列出台北本週起的各週，過去週次的資料雖保留在資料庫，畫面上卻找不到。使用者要求預設維持本週起往後看，但也能選擇先前的週次閱覽，且過去週次不能再編輯。

## 決策

- 預設畫面不變：本週一（台北日期）起連續列出各週，可編輯。
- 頁首加「查看過去週次」選單，列出聚會日期早於本週一的週次，最近的在前。選一週後只顯示那一週，選回「本週起（可編輯）」回到原本畫面。
- 過去週次唯讀：不能點選節目編輯、不能儲存草稿、發布、下架、重建草稿、刪除後續版本，也不顯示學生通知單。版次選單保留，可切換查看各版內容。
- 過去週次預設顯示當時公開的版本；若草稿與公開版不同，草稿列在選單中標「未發布」。沒有發布過的週次顯示草稿並註明未發布。
- 伺服器同樣擋下：`assertEditableWeek` 以該週已存的聚會日期（沒有草稿時用手冊推算的日期）判斷，早於本週一就拒絕所有編輯動作與發送通知單，回「過去週次只能閱覽，不能編輯」。讀取不受影響。

## 取捨

過去週次一次只看一週，不做連續捲動，因為回顧通常是查某一週。若之後需要更正過去週次，再另議是否開放管理員解鎖。
