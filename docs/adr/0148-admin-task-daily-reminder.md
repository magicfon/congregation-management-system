# ADR-0148：管理待辦每日 LINE 提醒

2026-11-24，已接受。

## 背景

使用者要求：看板「管理待辦」有待辦事項時，發訊息提醒管理員。待辦散在看板兩個區塊：「管理待辦」（LINE 待連結、領圖待審、回報待確認、拒訪待審）與「學生通知單」（ADR-0146）。即時逐筆推播容易洗版，且管理員不一定要每件都馬上處理。

## 決策

- 比照 ADR-0145：設定存在 `settings` 表 `admin_task_reminder`（JSON：enabled、memberIds、lastRun），預設關閉；我的看板「管理工具」新增「管理待辦每日提醒」卡片，可開關、指定收件人、預覽目前內容、看上次排程。卡片與設定存取改為共用（`ReminderSettingsCard`、`src/lib/reminder-recipients.ts`），公眾演講週一提醒行為不變。
- 每日彙整一次：Vercel Cron `0 12 * * *`（UTC 12:00＝台北 20:00；Hobby 方案在該小時內觸發），端點 `/api/cron/admin-task-reminder`，Bearer `CRON_SECRET`。晚上發，管理員白天的處理已反映，隔天可安排。
- 內容只列有數字的項目：LINE 待連結成員、領圖申請待審、回報待確認、拒訪待審、學生通知單已發送未確認、需自行轉交、尚未發送或需重發，附我的看板連結。計算與看板同源（資料表 pending 計數、`studentNoticeOverview`）；通知單資料讀不到時只略過那幾行。全部為零就不發。
- 透過 `line_notifications` 佇列發送，id 由「台北日期＋成員」雜湊，同一天重跑不重複；只發給在籍、已連結 LINE 且未關閉通知的成員，12 小時後過期。
- 不自動以管理員角色當收件人：由管理員在卡片指定，避免開啟就發給不想收的人。

## 後果

- 待辦沒處理會每天提醒一次，直到清空；不想收可關閉或移除收件人。
- 新增待辦種類時，要同步加進 `adminTaskCounts` 與提醒文字。

## 修訂（2026-11-28）

使用者表示要的不是可設定的彙整提醒，而是看板「管理待辦」四項（LINE 待確認、領圖待審、回報待確認、拒訪待審）有待辦時才通知。

- 刪除我的看板「管理工具」的「管理待辦每日提醒」卡片與其設定 API（`/api/admin/admin-task-reminder`）；`settings` 的 `admin_task_reminder` 不再讀取。
- 不再計入學生通知單。
- 不需設定：自動發給所有在籍管理員（`role = admin`，已連結 LINE、未關閉通知）。
- 時機沿用每天晚上 8 點（台北）一則彙整，四項全為零就不發；同一天同一人只發一次。項目名稱與看板一致。
