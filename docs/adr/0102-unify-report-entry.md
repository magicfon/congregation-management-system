# ADR-0102：傳道回報統一用區域回報表單

2026-10-30，已接受。

## 背景

側欄「傳道回報」與看板地圖卡的「查看／提交回報」連到舊的「回報系統」（`/reports`）。那頁直接建立系統回報紀錄，不寫 Sheet「傳道區域回報」，也沒有 ADR-0100 的防呆。使用者要求傳道回報跟弟兄們用同一個介面。

## 決策

- 側欄「傳道回報」改連公布欄的區域回報（`/bulletin/territory-report`）。
- 看板地圖卡的連結改為「提交回報」，帶入該圖區號（`?area=N`），打開表單時自動加入標籤。
- `/reports` 改為轉址到區域回報；舊頁的列表、編輯、刪除一併移除，回報紀錄以 Sheet 為準。

## 取捨

舊頁可編輯、刪除系統回報紀錄，但那些紀錄不影響 Sheet 與交回，留著反而會讓兩邊不一致，所以不保留。
