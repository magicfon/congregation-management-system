# ADR-0093：管理頁對非管理員顯示沒有權限

2026-10-29，已接受。

## 背景

已登入的非管理員打開週中編排（/midweek/manage）或服務安排管理（/service-roster/manage）會被靜默導到公開頁，使用者不知道原因。使用者要求顯示「沒有權限，請與管理員確認」；沒登入的人讓他嘗試 LINE 登入；管理員仍能看到待確認帳號。

## 決策

- 已登入但非管理員：週中編排、服務安排管理、分區修正三頁共用 `NoPermission` 畫面，顯示「沒有權限」與「請與管理員確認」，附對應公開頁（若有）與「我的看板」連結，不再自動導走。
- 未登入：維持導向 `/login`（LINE 登入），帶回原頁面。
- LINE 登入但未連結成員：維持導向 `/pending-access`，並記錄於成員頁「待確認 LINE 帳號」供管理員連結（既有流程，不變）。
- 後端 API 權限檢查不變。
