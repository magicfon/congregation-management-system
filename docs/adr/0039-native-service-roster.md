# ADR-0039: 本站服務安排

日期：2026-10-03
狀態：已接受

## 需求確認

依使用者指定「輪值表功能盤點.md」設計。使用者確認首次匯入後以本站管理，手動安排＋自動補空缺，沿用 People 後由管理員調整資格。公開閱讀維持免登入、亮暗外觀及精簡手機排版。

## 決策

- `/bulletin/service-roster` 提供按週卡片，11 職務分招待、週末、設備、週中四組；原 Google 輪值表與組織表保留在收合參考內容。本站輪值資料獨立於既有傳道 Schedule。
- 第一次部署嘗試唯讀匯入 Google Schedule／History／People；失敗不阻擋整站部署，管理員可重新首次匯入。已有本站資料絕不重匯覆寫。週日期採原始 typed date 的完整年份、台北日期；Schedule 覆蓋同日期的 History。大會／停會說明轉成停排原因，不建立人員。
- 人員以既有啟用成員唯一精確姓名匹配。未對上者保留原姓名、停用待確認；不建立假帳號。People 未具名三列不推測資格；五個有效職務匯入，其餘由管理員設定。原有安排完整保留，資格或衝突問題提示，修改人選才要求資格。
- 麥克風 A/B、講台、影像、音響自動補空缺；不改已有格，停排週跳過，替補招待不阻擋兼任。设备服務不得与當週其他固定勤務重複；週末與週中不同場次的固定勤務可兼任。候選不足留空並明示。
- 以目標週之前的日期計次，麥克風 A/B 同類，優先少次／避免連週與隔週，計入啟用合資格零次數者。一次以最小成本配對全部空缺，不宣稱全域最優。前後週以實際七日日期判斷。自動結果是預覽，管理員儲存才發布。
- 全部修改由管理員 API 驗證，在 Prisma 交易內檢查全站排班 revision 後更新，避免多人互覆及部分提交。公開 API 僅含週日期、職務姓名及停排原因；資格與會員 ID 僅管理員可取。
- 保存所有週次，不自動刪歷史；統計直接由這份安排算出，包含未来安排但明示是安排次數而非完成勤務。替補招待不計次，停排週排除，呈現同週所有職務而非覆蓋。
