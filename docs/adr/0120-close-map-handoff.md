# ADR-0120：關閉地圖交接功能

2026-11-09，已接受。取代 ADR-0119，並停用 ADR-0025、0027、0028 的操作入口。

## 背景

使用者看過地圖交接（傳道預排、塗畫局部進度、交接、整張交回）的完整流程後，覺得太複雜，決定先關閉。

## 決策

- LINE 管理頁拿掉「地圖交接」格。弟兄管理頁一排三格：區域回報、傳道地圖、領圖申請。管理者管理頁上排同弟兄三格，下排服務安排、週中編排、管理公告、成員管理；拿掉左右虛線分隔。選單圖片改變，狀態鍵與 alias 升為 v8（`line_rich_menu_v8_*`、`cms-v8-*`），部署後需再按一次「發布至 LINE」。
- 我的看板拿掉「待交接」「排給我的地圖」區塊，以及我的地圖裡的「管理／傳道進度」連結與預排狀態文字；管理員待辦中心拿掉「待交接」分類。舊的 `?view=handoffs` 連結改捲到我的地圖。
- `/map/ministry/[id]` 一律導回我的看板（我的地圖），舊 LINE 通知裡的連結不會 404。沒有頁面就不會再產生交接通知。
- LINE 私訊拿掉「本週行程」「待交接」指令與快速回覆，只留「我的委派」「我的地圖」。
- 刪除成員不再因未完成的傳道安排而被擋，因為已沒有介面可以取消。

## 不變

- `ministry_visits` 資料表與既有資料保留，不做破壞性遷移；交接 API 程式保留，日後要重新開啟時再補入口。
- 交回地圖、區域回報、領圖申請、Sheet 同步都不受影響。
