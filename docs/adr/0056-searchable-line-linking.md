# ADR-0056：LINE 帳號連結可輸入搜尋

日期：2026-10-17
狀態：已接受

使用者確認「待確認 LINE 帳號」與「LINE 帳號配對」均改為可輸入搜尋、再從候選人選點選的介面。成員以姓名搜尋，LINE 帳號以顯示名稱、目前成員姓名或 UID 搜尋。候選保留完整識別資訊以區分同名者，關聯仍以成員 ID 寫入。

輸入或修改文字會清除原選擇；未明確選定候選不可提交，不以文字自動配對。更換來源 LINE 帳號會清除目標成員。目標僅列啟用且未綁定 LINE 的成員。保留確認對話框、既有後端驗證與配對通知，不更動配對資料規則。

待確認帳號保留獨立「建立新成員」入口，可沿用搜尋文字作為新姓名，確認姓名及權限後才建立並連結。搜尋支援鍵盤方向鍵、Enter、Escape 與中文輸入法；窄螢幕使用可捲動候選清單。
