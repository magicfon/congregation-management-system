# ADR-0128：Vercel 函式區域改為新加坡 sin1，與 Neon 同區

2026-11-15，已接受。

## 背景

使用者反映正式站載入慢。實測（經 Ubuntu）發現 Vercel 函式全部跑在預設的美東 iad1（`vercel.json` 未設 regions），Neon 資料庫在新加坡 ap-southeast-1。快取頁由香港邊緣節點回應約 0.15 秒，但需要跑函式的請求（如 `/api/auth/session`）要 0.4～0.46 秒；每次資料庫查詢都要從美東跨太平洋到新加坡來回，一頁多次查詢延遲會累加。台灣到 Neon 的 TCP 連線只要約 0.05～0.065 秒，資料庫本身不是瓶頸。

## 決策

- `vercel.json` 加 `"regions": ["sin1"]`，讓 Serverless 函式與 Neon 同在新加坡。
- 使用者以決策卡同意（免費設定，可隨時改回）。

## 影響

- 函式到資料庫的往返由跨洋（約 200ms 以上）降為同區（數 ms），用戶到函式也從美東改到新加坡，離台灣更近。
- Cron 排程不受影響。日後若 Neon 搬區，需同步更新此設定。
