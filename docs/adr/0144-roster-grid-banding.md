# ADR-0144：服務安排一覽表隔週交替底色

2026-11-22，已接受。

## 背景

使用者反映管理服務安排的一覽表欄位多、列又密，橫向看一週時容易看錯行，要求每個週次跳色。

## 決策

- 一覽表（`ServiceRosterGrid`）的週次列依顯示順序隔列加 `roster-band`，該列儲存格疊一層 10% 的公布欄藍色（深色、淺色主題各自用 `--bulletin-blue`），疊色保持不透明，固定欄捲動時不透底。
- 跳色列的下拉選單底色改為透明，讓整列顏色一致；選單外框與尚未儲存（藍框）、資格待確認（黃字）的提示不變。
- 本週的週次欄仍用原本的強調底色，不被跳色覆蓋。
- 只影響一覽表；單週檢視與公開頁不變。
