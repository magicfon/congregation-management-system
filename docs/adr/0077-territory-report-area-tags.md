# ADR-0077：區域回報以標籤輸入多區

2026-10-24，已接受。修正 ADR-0076 的區域欄位。

使用者要求區域欄改成標籤模式：輸入完按 Enter 變成一個標籤，點標籤可取消。

- 輸入區號（1–213）按 Enter、逗號或空白即成標籤，顯示「地區＋號碼」；重複的不加入，找不到的號碼提示不加入。點標籤取消；輸入框空白時按退格刪掉最後一個。
- 自己領取中的地圖列在欄位下方作為快捷按鈕，點一下加入。不預先選取：預選全部會讓忘了取消的地圖一起被交回。
- 一次最多 20 區。各區共用傳道時段、開始日、結束日與備註；每區在 Sheet「傳道區域回報」各寫一列（一次 append），系統各留一筆紀錄，並各自依 ADR-0076 規則判斷是否交回。
- 全有或全無：任一區不存在、結束日早於自己那張的領取日、或重複送出，整筆不送出並指出區號。
- 送出前列出將被交回的地圖；包含他人領取的地圖時另外確認。
- API 改收 `sheetNos` 陣列，仍接受舊的單一 `sheetNo`。
