# ADR-0096: 區域狀況記住上次分區、輸入號碼跳轉

日期：2026-10-29
狀態：已接受

## 背景

區域狀況每次打開都固定顯示楠梓；常看梓官或橋頭的人每次都要再切一次。要找某一張地圖時，也得先知道它在哪個分區，再到地圖上找。

## 決策

- **記住分區**：選分區時存進瀏覽器本機儲存（`localStorage` 的 `area-status:last-map`），下次打開直接載入該分區。每台裝置、每個瀏覽器各自記，不存到伺服器；讀不到（無痕、封鎖儲存）就照舊用楠梓。讀取完才開始載入，避免先閃楠梓。
- **號碼跳轉**：標頭分區按鈕左邊加「區域號碼」輸入框與「前往」，按 Enter 也可。系統依號碼找出所屬分區（API 回傳全會眾 `numberMaps`：號碼 → 分區），必要時自動切換分區，載入後選取包含該號的區塊、展開地圖資訊，並把地圖移到該區塊。跳到的分區也會被記住。
- 找不到號碼顯示「找不到 N 號」；號碼存在但尚未定位在分區圖上，顯示「尚未定位在地圖上」。

## 取捨

- 不另做下拉搜尋或模糊比對，只接受整數號碼，保持介面精簡。
