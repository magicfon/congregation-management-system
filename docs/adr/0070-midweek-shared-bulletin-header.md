# ADR-0070：週中聚會閱讀頁共用公布欄標頭

2026-10-23，已接受。延續 ADR-0068、ADR-0069。

使用者反映週中聚會頁的介面和其他分類頁不同。原因是這一頁被排除在公布欄標頭之外：頂端是全站共用的空白頂列，只有外觀按鈕，返回箭頭則放在週次選單左邊，也沒有主選單。

## 決策

- `/bulletin/midweek-meeting` 改用和其他分類頁相同的標頭：左側「← 週中聚會」（h1），右側為外觀控制與 ☰ 主選單。全站共用的空白頂列不再出現在這一頁。
- 移除節目列上的返回箭頭與頁面內只給螢幕閱讀器的 h1，避免重複。週次選單、前一週／下一週與管理員的「編排」入口維持原樣。
- 內容區仍沿用較緊湊的留白，讓節目表盡量占滿畫面。
