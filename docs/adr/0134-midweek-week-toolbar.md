# ADR-0134：週中編排週卡的精簡工具列

2026-11-15，已接受。

## 背景

使用者表示週卡上「節目表設定」「發送學生通知單」「本週取消聚會」三個按鈕各佔一塊，太佔版面；「點選節目或姓名即可編輯。」提示文字也不需要。

## 決策

- 三個動作收成一列小按鈕：「節目表設定」「學生通知單」「取消聚會」。電腦版靠左、附小圖示；手機版三顆等寬排成一列、不顯示圖示。
- 「學生通知單」與「取消聚會」點開才在工具列下方展開原本的面板，同時只開一個；再點一次或按「收起／返回」收回。學生通知單一展開就讀取名單（原本要再按一次「發送學生通知單」）。
- 顯示條件不變：節目表設定與取消聚會只在可編輯且未取消時出現；學生通知單只在已發布、非過去週次時出現。取消後的「本週無聚會：原因／恢復聚會」橫幅照舊（ADR-0131）。
- 移除「點選節目或姓名即可編輯。」提示。
