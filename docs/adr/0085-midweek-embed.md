# ADR-0085：週中聚會的無邊框嵌入版

2026-10-28，已接受。

使用者要求週中聚會頁面也比照公眾演講（ADR-0084）做一個嵌入版，放進舊版 Google 協作平台。

- 網址 `/bulletin/midweek-meeting/embed`，免登入；加入嵌入白名單，其他未列入的分類仍回 404。
- 與公開週中聚會頁相同的節目表：保留週次選單與前一週／下一週按鈕，預設週次與 `?week=` 參數規則不變。
- 不包 `DashboardLayout`，沒有網站標頭、主選單與外觀按鈕；不呼叫 `/api/me`，所以也不顯示管理員的「編排」入口。
- 固定淺色（節目表紙張配色原本就固定），內容超過 iframe 高度時在框內捲動。
- 無資料庫、Sheet 同步或 LINE 變更。
