# ADR-0110：地圖分配移除「圖例與資料資訊」

2026-11-05，已接受。

## 背景

地圖資訊下方有可展開的「圖例與資料資訊」，列出可上色／灰色塊數、計算日期與同步時間、分區草稿版本、尚未定位的號碼。使用者認為用不到，要求刪除。

## 決策

- 整段刪除，API 回傳欄位不變。
- 色階（0 天～最多天數）與「已分發地圖顯示灰色」仍在地圖上方；回報日期尚未同步時，點選地圖的明細本來就會顯示「回報日期尚未同步」。
- 尚未定位的號碼改由「前往」得知：輸入該號會提示「尚未定位在地圖上」（ADR-0096）。

## 取捨

同步時間與分區草稿版本不再顯示在此頁；需要時到分區編輯器或 Sheet 同步頁查看。
