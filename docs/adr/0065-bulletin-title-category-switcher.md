# ADR-0065：公布欄分類頁以標題下拉切換

2026-10-23，已被 ADR-0066 取代；原調整 ADR-0064 的「分類切換收合」。

使用者不要「分類」按鈕展開的兩欄方框標籤，也考慮過漢堡選單。因全站側欄已使用漢堡選單，兩個漢堡易混淆，使用者選擇標題下拉。

## 決策

- 分類頁標題本身即切換器：「服務安排 ▾」，點擊展開七個分類的直式清單，每列為分類圖示與名稱，目前分類加底色與勾號；移除原「分類」按鈕。
- 手機（640px 以下）由底部滑出，背景加暗、保留拖曳把手樣式與安全區留白；桌面為標題下方 16rem 浮窗。每列至少 48px 高。
- 點選分類、點外部或按 Escape 關閉；Escape 後焦點回到標題。標題仍是頁面唯一 `h1`，按鈕帶「切換分類」無障礙說明。
- 返回公布欄箭頭與首頁七分類入口保留；週中聚會閱讀頁維持原本無分類列的版面。

## 後果

少一顆按鈕，切換入口與目前位置合一；首次使用者需靠箭頭圖示辨識標題可點。清單沿用公布欄分類圖示，未新增色彩或字體。
