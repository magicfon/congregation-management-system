# ADR-0126：LINE 管理頁「區域狀態」格與區域狀態頁

2026-11-14，已接受。取代 ADR-0125 的「我的區域」選單格。

## 背景

ADR-0125 把「領圖申請」格改成「我的區域」，開看板的我的地圖。使用者更正：這格應叫「區域狀態」，要看到現在哪些人領著地圖、各領哪些地圖，以及自己申請地圖的狀態。

## 決策

- 新頁 `/territory-status`「區域狀態」（需登入，所有成員可看；middleware 兩份清單都加上）。
  - 上段「我的申請」：自己的待審申請全部列出，已核准／已拒絕／已取消只列最近 5 筆；有申請時連到 `/map-requests` 取消或看全部紀錄，另有「到傳道地圖申請」。管理者的申請 API 會回全部人的申請，頁面只取自己的。
  - 下段「目前領圖」：依人列出持有的地圖與領取天數（30 天以上黃、60 天以上紅、沒有領取日顯示「日期待補」），自己排第一並標「我」，可搜尋人名或號碼。資料沿用 `/api/areas/dispatched`（使用中地圖頁同一來源），不新增 API。
- LINE 弟兄與管理者管理頁左下第二格改為「區域狀態」（副標「領圖情況與我的申請」），LIFF view `territory-status`。
- 狀態鍵與 alias 升為 v11，部署後需在「我的看板→管理工具→底部圖文選單」再按一次「發布至 LINE」。
- 側欄不加新項目（介面精簡）；使用中地圖頁（管理用，含收回與 LINE 提醒）不變。
