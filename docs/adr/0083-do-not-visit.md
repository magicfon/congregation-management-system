# ADR-0083：拒絕拜訪地址與 Sheet J 欄雙向同步

2026-10-28，已接受。

使用者在 Sheet「區域狀態」J 欄「拒絕拜訪」記錄住戶要求不再拜訪的地址，但系統完全沒讀這一欄，傳道時看不到。使用者要求地圖系統也能標註，並與 Sheet 雙向同步。

## 決定

- **資料**：`areas.doNotVisit` 存該區 J 欄全文（換行正規化、去頭尾空白）。顯示時以換行或半形逗號切成多筆；網站寫入一律一行一個地址。註記直接接在地址後（例如「聖公路32號 有凶狗」），所以不用全形逗號、頓號切分。
- **同步**：比照 C/D 欄，在 `sheet_j_snapshot` 設定保存上次同步時 213 區的 J 欄內容。
  - Sheet 與快照不同、系統沒變：Sheet 改了，匯入系統。
  - 系統與快照不同、Sheet 沒變：網站改了但寫回失敗，補寫 Sheet。
  - 兩邊都變：合併，Sheet 的地址在前，系統獨有的接在後，寫回兩邊並記一筆衝突。不丟任何一邊的地址。
  - 第一次同步沒有快照：以 Sheet 為準匯入（系統原本沒有資料）。
  - 每次同步更新全部 213 區的快照。
- **網站編輯**：管理員在區域狀況「設定」面板編輯整格內容（一行一個），以舊值當條件避免覆蓋他人修改；存檔後立刻寫 J 欄並更新快照。寫 Sheet 失敗時系統已存，下次同步補寫。
- **回報**：區域回報只選一區時顯示選填「拒絕拜訪地址」（最多 100 字、單行）。與回報同一筆 transaction 建立 `do_not_visit_reports` 待審紀錄，不直接寫入。管理待辦新增「拒訪待審」，管理員核准就附加到該區（已存在相同地址則略過）並寫 J 欄；不採用則只標記。
- **顯示**：只列文字，不在地圖上打點，因為分區圖沒有經緯度，門牌無法準確定位。
  - 傳道頁（`/map/ministry/[id]`）標題下方黃框「拒絕拜訪」逐行列出。
  - 我的看板地圖卡片摘要列顯示「拒訪 N 筆」。
  - 區域狀況點選地圖後的地圖資訊列出地址。
  - 只有登入成員看得到，免登入的回報頁不顯示。

## 影響

- 新增欄位與資料表透過部署 SQL（`prisma/do-not-visit.sql`）建立。
- 同步的 J 欄讀寫都用 RAW，不會執行公式。
- 部署後依 AGENTS.md 連打同步兩次，第二次應全零；第一次會把 J 欄現有內容匯入系統並建立快照。
