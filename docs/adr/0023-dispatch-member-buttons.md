# ADR-0023：可設定的派發人選按鈕

狀態：Accepted，2026-09-29

使用者確認派發人選改成獨立姓名按鈕，並由成員管理設定哪些人顯示；預設列出所有啟用中成員。Member 新增 showInDispatch，預設 true，只有管理員可更新。

區域狀況與地圖分配共用按鈕選擇器，僅列出 active 且 showInDispatch 的人選。選取有明確勾選狀態，最後確認才派發；空清單提示前往成員管理設定。關閉顯示不會停用帳號、改動持有地圖或申請權限。

資料庫以可重複執行的新增欄位 SQL 隨部署執行；既有 API 客戶端省略設定時，更新保留原值、建立使用預設 true。
