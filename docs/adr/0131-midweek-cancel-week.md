# ADR-0131：週中編排「本週取消聚會」

2026-11-15，已接受。

## 背景

使用者說有時候週中聚會會取消（例如大會、分區監督探訪），編排介面要能一鍵處理，並標注是因為什麼活動或原因沒有聚會。

## 決策

- 節目表（`Meeting`）新增選填欄位 `cancelled`（原因，最多 60 字）。有值就代表這週沒有聚會；節目與人員照樣保存在節目表裡，不刪除。
- 編排頁每週卡片多一個「本週取消聚會」按鈕：選常用原因（大會、分區監督探訪、紀念聚會、特別活動）或自填，按「取消聚會並公開」直接發布成新版次，公布欄即時改成「本週無聚會：原因」。
- 取消的週顯示紅色橫幅與「恢復聚會」按鈕，按下確認後再發布一版，原本的節目與人員回到公布欄。取消期間不能編輯節目內容。
- 取消與恢復都走一般的發布流程：各算一個版次，草稿鎖定、過去週次唯讀、刪除後續版本等規則照舊。草稿有未發布修改時先確認，修改會一起保存，恢復聚會時才公開。
- 公開頁與嵌入頁：節目表只留日期與經文標頭，中間顯示「本週無聚會」與原因；週次選單標「（無聚會）」。編排頁標題列狀態顯示「無聚會」。
- 我的委派（網站與 LINE）跳過取消的週。學生通知單在取消的週沒有學生；先前發過的人在名單上列為「取消」，管理員按發送就會收到取消訊息（沿用 ADR-0090）。

## 取捨

不用「下架」或清空人員：下架後公布欄只是看不到那週，看的人不知道為什麼；清空人員則無法恢復。用欄位標記並保留內容，代價是取消的週在資料上仍帶著原本的節目，所有讀取已發布節目的地方都要檢查 `cancelled`。
