# ADR-0147：我的委派納入公眾演講秩序表的週末聚會委派

2026-11-24，已接受。

## 背景

使用者反映公眾演講和朗讀沒有出現在我的看板「我的委派」。原本只合併兩個來源：服務安排（含守望台朗讀、週中主席／朗讀）與已發布的週中節目。週末聚會的講者、主席、誦讀只寫在公眾演講秩序表（公開試算表，ADR-0145 同一份），從未被讀進委派。

## 決策

- 我的委派多讀公眾演講秩序表，分類標「週末聚會」，連到公布欄「公眾演講」。
- 依欄位比對成員姓名（與週中節目同樣需要姓名唯一）：
  - 講者 → 「公眾演講 編號 講題」，角色「講者」。外地講者寫成「姓名（會眾）A」，比對前去掉括號之後的文字。
  - 主席 → 「週末聚會主席」。
  - 誦讀 → 「守望台誦讀」。同一週服務安排已經排本人守望台朗讀時不重複列。
- 「守」欄只寫姓、「外地演講」欄是自由文字（姓＋會眾＋講題編號），無法可靠對應，不納入。
- 年份推算沿用每週提醒的規則（`datedPublicTalkRows`）：第一列取離本週最近的一年，之後依「2027年」分隔列與月份倒退跨年。
- 試算表讀不到時，其他委派照常顯示，另提示「公眾演講秩序表暫時讀不到」。LINE「我的委派」與 AI 問答共用同一份資料，一併生效。

## 後果

- 每次讀看板或 LINE 我的委派會多抓一次試算表 CSV（15 秒逾時）。
- 試算表與服務安排的守望台朗讀若排了不同人，兩邊各自顯示，需由編排者對齊。
