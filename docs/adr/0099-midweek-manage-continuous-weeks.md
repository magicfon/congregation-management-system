# ADR-0099: 週中編排頁連續顯示多週

日期：2026-10-30
狀態：已接受

## 決策

使用者要求編排委派的介面不要一週一週切換，要連續顯示好幾週；畫面夠寬時左右各放一週；往下滑才載入下一週，不預先載入。

- `/midweek/manage` 拿掉週次下拉選單與前一週／下一週按鈕，改為本週起依日期往下排列各週（`MidweekManager`）。
- 每週一張獨立的編排區（`MidweekWeek`）：週次標題與狀態、版次紀錄、儲存／發布、學生通知單、節目表。各週的草稿、未儲存提醒、版次選擇互不影響，不用再「切換週次」。
- 只先載入第一週；捲到底部、且已顯示的週都載完，才載入下一週。寬螢幕（每欄至少 34rem）兩欄並排，同一列空著的欄位會補上下一週；版面寬度上限 1600px，因此最多兩欄。窄螢幕一欄上下連續。
- 「更多管理」只留全站的手冊匯入、下次檢查時間與來源錯誤；「下架這週」與「手冊來源與重建草稿」移到各週的「這週的手冊與下架」。
- 公開節目表與嵌入頁維持一次一週與前後週按鈕，`Midweek` 只負責公開顯示。

## 後果

寬螢幕兩欄時節目表縮得比較小，仍可用 Ctrl＋滾輪或雙指縮放。每多顯示一週多一次讀取，但只在捲到時才發生。視窗寬度改變後，下一次捲動才會依新的欄數補齊。
