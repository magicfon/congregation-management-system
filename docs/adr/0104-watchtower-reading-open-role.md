# ADR-0104: 守望台朗讀與招待不用設定資格

日期：2026-10-31
狀態：已接受

使用者表示守望台朗讀每個人都有資格，不用特別設定。原本所有職務都要在人員資格勾選才能排，守望台朗讀沒人設定，導致 Sheet 同步匯入時報「守望台朗讀人選尚未具備資格」，本站也選不到人。

- 守望台朗讀列為「不需資格」的職務：人員資格名單上可安排的人都能排，伺服器驗證、Sheet 匯入、管理頁下拉選單與「資格待確認」提示都照此判斷。
- 人員資格總表與進階設定不再顯示守望台朗讀，避免誤以為要勾。
- Sheet 上的姓名仍須在人員資格名單上（不同名），才能對到人。
- 其他職務維持原本的資格規則；自動補空缺不涉及守望台朗讀。

2026-10-31 補充：使用者表示招待也不用設定資格。招待當值、替補招待、會堂招待員一併列為不需資格的職務，規則同上。

2026-10-31 再補充：使用者表示沒有設定任何資格的職務就不卡資格。除了上述固定不需資格的職務，名單上沒有任何人勾選的職務也視為人人可排；一旦有人勾了該職務，就只限有勾的人。人員資格總表在這類職務顯示「未設定資格，人人可排」。自動補空缺仍只挑有勾資格的人。
