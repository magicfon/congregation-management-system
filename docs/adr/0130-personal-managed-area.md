# ADR-0130：地圖「個人管理」分類

2026-11-15，已接受。

## 背景

使用者說有些地圖不分發，固定由特定的人自己管理，他自行回報什麼時候領取、什麼時候完成。現有的「個人區域」（ADR-0036）人人可申請、完成就交回；「自主管理地圖」成員設定（ADR-0101）不限定地圖、只記完成。兩者都不符合。使用者確認個人區域保留，是不同概念。

## 決策

- 地圖分類改為三種：一般區域、個人區域、個人管理。新增 `areas.personalManaged`，與 `personalTerritory` 互斥；分類設定改用 `category` 操作，帶原分類做條件檢查。
- 設為個人管理時指定一位啟用中的成員，管理人就是持有人（`assignedMemberId`）。地圖若由別人領取中，要先收回；已由他領取就沿用領取日，否則以設定當天為領取日。待審的領圖申請一併駁回，派發撤銷紀錄清除。可直接更換管理人。
- 個人管理的地圖不能分發、申請、收回（單張／批次／回報待確認的交回與以 Sheet 為準都擋）。要改先把分類改回一般或個人區域，持有人保留，再照一般流程收回。
- 區域回報：管理人或管理員回報時，開始日記為領取日、結束日記為完成日，不交回、免確認；Sheet 回報列記在管理人名下。只有結束日不早於現有最後完成日的回報才更新領取日，補報較舊的只留紀錄。其他人回報直接擋下。姊妹是管理人也能回報。
- Sheet「區域狀態」：C 欄固定寫管理人，D 欄跟著領取日更新（使用者 2026-11-15 確認）。站內回報後即時寫入；寫入失敗由 cron 補推 D 欄。管理人用 Google 表單回報，cron 也同樣更新領取日、不交回。Sheet C 欄被改成別人時以系統為準並建待確認。
- 個人管理的地圖不產生「回報了卻未交回」待確認。
- 地圖分配與地圖清單標「個人管理」，持有人改稱管理人。

## 取捨

管理人直接用持有人欄位，不另開欄位，分配、看板、我的地圖、Sheet C 欄都沿用；代價是取消個人管理後地圖仍在原管理人名下，需要管理員自行收回。
