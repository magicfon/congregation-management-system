# ADR-0080：人員資格在職務列直接新增、移除

2026-10-24，已接受。補充 ADR-0075。

使用者覺得人員資格要先在下方表單選人、勾職務再儲存很不方便，要求在職務一覽上直接點擊就能新增人員。

- 每個職務列最後加「＋新增」，點開成員選單，選好立即儲存；選單列出所有啟用成員，扣掉已具備此資格的人。
- 選到的成員若已在資格名單，沿用他原本的其他資格與可安排狀態，只加上這項職務；若還不在名單，新建一筆並設為可安排。
- 已對應成員的人名旁加 ×，確認後移除該職務資格。待對應的人沒有成員連結，不能從這裡移除，需先在進階設定對應。
- 原本的人員表單收進「進階設定：對應成員、停用」，預設收合；點人名會展開並帶入該人。
- 沿用既有 `person` 管理動作與版本檢查，不新增 API。
