# ADR-0102：LINE 圖文選單依管理者／弟兄／姊妹分三版

日期：2026-10-30；狀態：已接受

使用者要求不同身分在 LINE 官方帳號看到不同選單，並明確選擇固定三版、不依持有地圖動態切換（避免選單一直變）。

- 姊妹版（4 格，2×2）：公佈欄、我的看板、我的委派、傳道地圖。設為官方帳號預設選單，未設性別、未連結、停用或刪除的人都看這版。
- 弟兄版（5 格，上 3 下 2）：姊妹版再加區域回報。依成員性別 `brother` 判斷。
- 管理者版（6 格，3×2）：弟兄版再加管理入口。依 `role === 'admin'`，不分性別。

「地圖交接」格（弟兄與管理者）使用者決定先隱藏，等多數弟兄連結 LINE 後再啟用並完善功能。程式以 `SHOW_HANDOFFS`（`src/lib/line-rich-menu.ts` 與 `scripts/create-line-menu.cjs` 各一）控制；開啟時弟兄 6 格、管理者 7 格，需重新產生圖片並將狀態鍵升版後再發布。

傳道地圖改開地圖分配頁（`/area-status`，可申請個人區域）；原本開待交接的功能日後由「地圖交接」（`/dashboard?view=handoffs`）承接。區域回報開 `/bulletin/territory-report`；管理入口開 `/dashboard?view=manage`，定位到看板的常用管理連結。我的委派維持訊息動作。

實作沿用 ADR-0047 的發布鎖與 expectedCurrentId。發布時建立三個選單（狀態鍵 `line_rich_menu_v5_{kind}`，舊 v4 選單不刪），姊妹版設為預設，再以 bulk link 把現有弟兄與管理者綁上各自選單。之後在成員改權限／性別／帳號狀態（成員編輯、性別批次、人員設定）、LINE 配對、待確認帳號連結或建立、刪除成員時，對該成員個別 link 或 unlink。三個選單都發布前不做個別切換；切換失敗只記錄，不擋原操作，可再按一次發布補綁。

選單圖片由 `scripts/create-line-menu.cjs` 產生，`scripts/check-line-menu.cjs` 驗證圖片尺寸、格子位置與切換流程。
