# ADR-0127：LINE「我的委派」私訊不附網址、日期改中文寫法

2026-11-15，已接受。修改 ADR-0055 的 LINE 回覆格式。

## 背景

LINE 官方帳號回覆「我的委派」時，每段後面附網站連結，日期寫成 `2026-11-15`。使用者表示資訊不用附網址；而 LINE 會把這種日期自動辨識成超連結，點了會跳出行事曆／選單，造成干擾。

## 決策

- 「我的委派」回覆拿掉各段落的網址與結尾「請開啟上述連結」，結尾改為「完整委派與過去紀錄請至網站「我的看板」查看。」
- 日期改寫成「11月15日（日）」，跨日服務寫成「11月15日（日）～11月21日（六）」（台北日期字串直接換算星期，不經時區轉換）。
- 「我的地圖」與其他回覆不在此次範圍，維持原樣。
