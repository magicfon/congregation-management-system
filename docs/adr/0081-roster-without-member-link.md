# ADR-0081：服務安排不需連結成員

2026-10-24，已接受。修正 ADR-0039／0073／0075／0080 中「待對應」的規則。

使用者表示不用「待對應」，有安排就是有安排：資格名單上的人只要有該職務資格就能排，不必先連到本站成員。

- 資格名單上沒連成員的人視為可安排，下拉選單、自動補空缺、伺服器驗證與 Google 匯入都不再要求成員連結。
- 有連成員的人照舊：勾「可安排」且成員仍啟用才可排；成員停用或刪除時自動不可排。
- 沒連成員的人無法單獨停用；不想再排就移除他的資格，或在進階設定連到成員後取消「可安排」。
- 介面不再顯示「待對應」標記與人數。職務列的 × 對所有人都可用；進階設定改稱「連結成員」，沒連成員的人可直接改資格、維持名單姓名。
- 成員連結仍用於「我的委派」高亮與看板：沒連成員的人登入後看不到自己的安排被標出來。
- 首次匯入時對不到成員的人也設為可安排。未來 Sheet 出現名單上沒有的姓名仍會提示，請先在人員資格新增。
