# ADR-0123：地圖分配手機固定領圖操作列與已選張數

2026-11-12，已接受。補充 ADR-0107。

## 背景

使用者反映地圖分配（分發系統）在手機上太吃力：選好地圖後，「加入分發清單」按鈕放在地圖資訊最下面，要在很小的側欄裡一直往下滑才按得到；已經選了幾張也不清楚（只在清單標頭有一行小字）。

## 決策

- 手機版在畫面最下方固定一條領圖操作列，永遠看得到：左邊是「＋ 加入分發／加入申請」（多張地圖的區塊每張一顆，標號碼；已加入的變成「✓ 已加入 · 移除」），右邊是「已選 N 張」（申請模式為「已選 N / 5 張」）徽章，按下展開派發／申請清單。還沒點地圖時左邊提示「點地圖選擇要分發的區域」。
- 電腦版同一條操作列放在地圖資訊面板底部（選取區塊時才出現），不用捲到明細最下面。原本明細內的加入按鈕移除，避免兩處重複。
- 已選張數改成實心藍底徽章（有選時），清單標頭與操作列共用。
- 手機頁首精簡成一列：隱藏「地圖分配」標題（頂端列已有）、號碼輸入框縮窄、重新整理只顯示圖示；地圖與側欄比例由 0.9：1.1 調為 0.8：1.2，讓側欄多一點空間。可收合區塊加 `overflow-hidden`，空間不足時標頭不再互相重疊。

## 取捨

不另做彈出式底部抽屜，維持現有側欄結構，改動最小；明細內容在手機上仍可能需要在面板內捲動，但加入與查看清單不再需要捲動。
