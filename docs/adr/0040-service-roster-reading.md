# ADR-0040: 服務安排閱讀排版

日期：2026-10-03
狀態：已接受

使用者反映服務安排不易瀏覽，要求重新設計。沿用既有按週閱讀流程，先以本週精簡清單改善：手機職務兩欄、姓名放大、前後週與回本週直接操作。週次選單保留完整年份與日期，避免跨年混淆；未儲存切週仍確認捨棄。

服務安排頁縮短頁首，分類導覽收合；外觀按鈕在手機以具備可存取名稱的圖示呈現。四組職務維持原分類與完整名稱，管理員編輯時保留適合選人的單欄欄位。原表與統計維持收合。排班資料、資格與發布流程沿用 ADR-0039。

使用者確認分類配色：招待藍、週末紫、設備青綠、週中橙。標題、左側色條與淡背景使用分類色；姓名沿用高對比文字，分類文字保留，亮暗模式分別使用深／淺色標題。

使用者反映老花閱讀困難，服務安排姓名提升至 24px、職務與分類 18px，日期與操作至少 16px；增加行距、格距、按鈕高度並加深亮色分類文字。

使用者指定設備分組改為「麥克風」（A/B）與「講台／音響／影音」（講台、音響、影像），兩頁同步顯示。職務名稱加粗並搭配分類色底，公開頁 20px、編輯欄位 18px；姓名維持 24px。自動補空缺與資格規則維持原職務 ID。

使用者確認職務加圖示：名稱左側放既有 Lucide 圖示（迎賓、成員、書本、麥克風、簡報講台、喇叭、螢幕、主持），保留完整文字與 20px 職務字級，圖示對輔助科技隱藏以避免重複朗讀。窄於 380px 的手機採單欄，其他手機維持兩欄；管理選人欄位在窄螢幕上下排列以免擠壓。

使用者確認改用專用原創 SVG：以 28 單位網格、粗圓角線條繪製迎賓、替補、入口招待、書本、手持麥克風、實體講台、音控台、播放螢幕與主席。顯示尺寸 24px，沿用分類色與文字，無外部圖檔請求。
