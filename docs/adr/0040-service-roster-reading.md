# ADR-0040: 服務安排閱讀排版

日期：2026-10-03
狀態：已接受

使用者反映服務安排不易瀏覽，要求重新設計。沿用既有按週閱讀流程，先以本週精簡清單改善：手機職務兩欄、姓名放大、前後週與回本週直接操作。週次選單保留完整年份與日期，避免跨年混淆；未儲存切週仍確認捨棄。

服務安排頁縮短頁首，分類導覽收合；外觀按鈕在手機以具備可存取名稱的圖示呈現。四組職務維持原分類與完整名稱，管理員編輯時保留適合選人的單欄欄位。原表與統計維持收合。排班資料、資格與發布流程沿用 ADR-0039。

使用者確認分類配色：招待藍、週末紫、設備青綠、週中橙。標題、左側色條與淡背景使用分類色；姓名沿用高對比文字，分類文字保留，亮暗模式分別使用深／淺色標題。

使用者反映老花閱讀困難，服務安排姓名提升至 24px、職務與分類 18px，日期與操作至少 16px；增加行距、格距、按鈕高度並加深亮色分類文字。
