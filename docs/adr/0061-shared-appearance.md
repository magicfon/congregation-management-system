# ADR-0061：全站共用外觀入口

日期：2026-10-19
狀態：已接受（使用者確認「採用，請直接統一」）

## 決策

- 全站固定於頂端右上角提供單一「外觀」按鈕，展開選擇淺色、深色、跟隨裝置；手機與桌面一致。
- 登入頁、看板、管理頁、公佈欄及週中節目表皆提供入口，移除個別頁面切換列。
- 根版型統一管理偏好，沿用 bulletin-theme 裝置儲存值；預設跟隨裝置，切頁及跨分頁保持一致。
- 共用工具列預留高度，避免遮住內容與手機導覽。PDF、地圖及節目表紙張維持原始配色。

## 原因與後果

集中管理可避免新頁漏放入口或出現不同名稱與位置；固定工具列占用少量垂直空間，但所有頁面均可直接找到。全螢幕閱讀及模態視窗保留較高圖層，關閉後回到共用入口。
