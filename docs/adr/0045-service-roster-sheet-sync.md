# ADR-0045: 每週服務安排雙向同步

日期：2026-10-04
狀態：已接受

使用者確認只同步每週安排，成員連結與職務資格仍由本站管理；取代 ADR-0039 的不寫回決策。Schedule 與 History 的安排列按完整週開始日期識別，People 完全不讀寫。欄位按來源標題對應，尤其 L 是影像、M 是音響，不以本站顯示順序推測。

本站儲存週次後嘗試同步；失敗仍保留本站儲存並明示待同步。管理頁提供同步與衝突比較。既有 cron 觸發同一服務，保留目前外部排程頻率。同步不由公開 GET 觸發。

以每週最後成功同步的內容作三方比較；只有一方更動才自動傳送。首次兩邊不同、兩邊同時修改、Schedule/History 同週分歧或來源列移除，均保留資料並要求管理員選擇。來源單邊移除不自動刪除本站。解決衝突必須帶最新版本與衝突指紋，避免確認過期內容。Sheet 新姓名不自動建立成員或資格，先要求管理員於本站對應。

使用既有 REST OAuth client 與 taipeiDate。讀取 unformatted serial dates；寫回 RAW 值，保留格式、不覆蓋公式。P/Q 空白欄可建立備註／停排欄以完整表示週次資訊，若已有其他用途則停止。合併儲存格阻礙安排写入時停止並提示，不自動拆除版面。

DB 同步使用交易 advisory lock 並鎖定排班 revision，避免同步與本站儲存交錯；Google 寫入前重讀確認，寫入後核對才推進快照。Google Sheets 不提供 values compare-and-swap，外部編輯與最後檢查間仍有極短競爭窗口；失敗不宣稱同步成功。既有快照、衝突與狀態存 Setting，無新增部署 DDL。
