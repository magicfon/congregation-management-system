# ADR-0075：人員資格總表改以職務為主

2026-10-24，已接受。取代 ADR-0073 的「人員 × 職務」矩陣。

使用者說明管理時是從服務崗位出發：先看 A 服務有哪些人可以安排、B 服務有哪些人，而不是看每個人有哪些資格。

- 「人員資格」區塊上方依 `serviceRoles` 順序每個職務一列：職務名稱、「N 人可安排」，右側列出具備此資格的人名。
- 可安排的人在前；停用、待對應的人仍列出，但字較淡並加上標記，不算進人數。沒有人可安排時人數以琥珀色提醒，沒有任何人具備資格時顯示「尚無人具備此資格」。
- 總表只供檢視。點人名帶進下方既有表單編輯，同一人在每個職務的名字都會標成選取中。
- 手機上職務名稱在上、人名在下自動換行，不需要橫向捲動。
