# ADR-0079：服務安排管理一覽表

2026-10-24，已接受。補充 ADR-0041 的管理頁。

使用者覺得管理服務安排要一週一週切換挑人很不方便，要求一覽的表格。

- 管理頁 `/service-roster/manage` 上方加「一覽表／單週」切換，預設一覽表；單週檢視維持原本功能（停排、備註、單週自動補空缺）。
- 一覽表每列一週、每欄一個職務（順序同 `serviceRoles`），格子是下拉選單，只列具備該職務資格且已對應成員的人；選單內標出同週已排其他職務的人。原安排人員不再具資格時保留並標「資格待確認」。
- 預設只顯示本週起的週次，過去週次可展開。停排週整列顯示停排原因，不在表上改；點日期切到該週單週檢視設定停排與備註。
- 修改先留在畫面上（藍框），兼任重複或資格待確認標黃字。底部浮動列顯示幾週有修改，可「捨棄」或「儲存並發布」，多週一次送出。
- 「自動補空缺」對本週起所有未停排週次依序補五項設備服務空缺（沿用 ADR-0039 的演算法），前面週次補上的人計入後面週次的輪替紀錄；只填到畫面，儲存後才發布。
- 管理 API 新增 `weeks` 動作，在同一交易內逐週驗證並寫入（同 `week` 的資格與兼任檢查），任一週不通過整批不寫入並指出哪一週；儲存後照常同步 Google。一次最多 60 週。
- 一覽表有未儲存修改時，Google 同步、新增週次與人員資格區暫時隱藏或停用，切換檢視前會確認是否捨棄。
