# ADR-0118：週中編排提示不在成員名單的姓名

2026-11-06，已接受。

## 背景

「我的看板」與 LINE「我的委派」依姓名比對週中節目表的主席、負責人／學生、助手（`personal-assignments.ts`）。編排時打錯字，該弟兄姊妹就看不到委派，編排的人也不會發現。使用者希望打錯名字時提示「成員名單沒有這個人」。

## 決策

- 編排頁的姓名欄（節目表上的主席、負責人／學生、助手，以及節目設定視窗的負責人／學生、助手）離開欄位時，若姓名（去頭尾空白）不在啟用中的成員名單，跳出確認視窗：「「○○」不在成員名單中，確定要委派嗎？」
  - 按「確定」保留姓名；同一欄位再次離開時不再詢問同一個姓名。
  - 按「修改」（或 Esc）回到該輸入框並選取文字，方便改正。
- 不標紅、不在發布時另外擋；外來講者等不在名單的人按確定即可。
- 只在編排頁，公開節目表與嵌入頁不受影響。成員名單沒載入或切換視窗造成的離開不詢問。
- 實作在 `src/components/bulletin/useMemberNameCheck.tsx`。

### 修訂（2026-11-07）

最初版本（PR #81）是欄位標紅、節目表上方列出姓名、發布時再確認。使用者說明要的是離開輸入框當下跳出確認、可選確定或修改，因此改為上述做法，移除標紅、列表與發布確認。

## 影響

- 純前端提示，無資料庫、API、Sheet 同步或 LINE 變更。
