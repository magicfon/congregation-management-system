# ADR-0118：週中編排提示不在成員名單的姓名

2026-11-06，已接受。

## 背景

「我的看板」與 LINE「我的委派」依姓名比對週中節目表的主席、負責人／學生、助手（`personal-assignments.ts`）。編排時打錯字，該弟兄姊妹就看不到委派，編排的人也不會發現。使用者希望打錯名字時提示「成員名單沒有這個人」。

## 決策

- 編排頁的姓名欄（主席、負責人／學生、助手）離開欄位後，若姓名（去頭尾空白）不在啟用中的成員名單，該欄加紅框與波浪底線，滑鼠移上顯示「成員名單沒有這個人」。
- 節目表上方列出「成員名單沒有：○○、○○」，說明不在名單的人不會在「我的委派」看到委派。
- 按發布時若仍有不在名單的姓名，跳出確認；可以照樣發布（例如外來講者），不強制擋下。
- 只在編排頁顯示，公開節目表與嵌入頁不顯示。成員名單沒載入時不提示，以免全部標紅。
- 比對邏輯放在 `src/lib/midweek.ts` 的 `unknownNames`。

## 影響

- 純前端提示，無資料庫、API、Sheet 同步或 LINE 變更。
