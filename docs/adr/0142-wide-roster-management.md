# ADR-0142：管理服務安排在電腦版放寬內容區

2026-11-22，已接受。

## 背景

使用者反映「管理服務安排」下方的一覽表太窄，要橫向捲動才看得到全部委派。公布欄版面內容區固定最寬 6xl（1152px），一覽表有 11 個職務欄、每欄至少 8rem，合計約 1500px，電腦上一定要捲動。

## 決策

- `DashboardLayout`／`BulletinLayout` 新增 `wide` 選項，只有 `/service-roster/manage` 使用：寬度 ≥1024px（`lg`）時內容區取消最寬限制、左右留白改為 1rem。標頭維持原寬。
- 一覽表在 `lg` 以上把職務欄最小寬度降為 6rem、週次欄 5rem，欄頭內距縮小；欄寬仍依職務名稱自動撐開。量測結果：1280px 以上視窗可一次看到全部 11 欄。
- `lg` 以上隱藏「可左右滑動」提示。
- 手機與平板直向（<1024px）所有樣式不變；其他公布欄頁面不受影響。
