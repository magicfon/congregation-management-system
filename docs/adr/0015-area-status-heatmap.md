# ADR-0015：區域狀況熱力圖

2026-09-26。使用者確認距上次完成回報與本次領取天數是不同資訊；本頁使用前者，後者保留於使用中地圖。

## 決定

新增受登入保護的 `/area-status` 與側欄入口，包 DashboardLayout。提供三區大圖、連續色帶、縮放平移、區塊明細及重新整理。`/api/area-status/[mapId]` 只讀 Neon 的區域完成日期、同步時間及分區草稿。

以 `lastReportedCompletedAt` 經 taipeiDate 轉換，再用 idleCalendarDays 計算；不讀取 dispatchedAt 或 completedAt。用全域 sheetNo 對應候選編號，避免將各地重複的 mapAreaId 當全域編號。採用可信原圖中繼資料並驗證、重算雲端幾何配對。只有草稿不存在才回退原始候選，資料庫或草稿驗證失敗回錯誤。

預設 0 天綠、90 天黃、180 天紅，兩段 RGB 線性內插、180 天以上維持紅。未同步、無回報、未配對及日期不完整顯示灰色，不把未知當新近完成。多編號且全部有日期時取最大天數，明示並列出逐號明細；候選仍為人工核對草稿。

圖層使用原图像素座標，以 Leaflet CRS.Simple 將 x,y 轉成 [height-y,x]。小區塊在上層，保留獨立重疊候選。頁面顯示計算日期、資料同步時間、草稿版本；切圖取消舊請求，避免快切後混用三區資料。未能在候選中定位的區域另行提示。

## 驗證

日期不依分發改動、台北跨日、色階端點、未知／未同步／多編號、全域編號對應、匿名拒絕、雲端優先與原始 fallback、失敗不冒充成功。TypeScript 檢查、瀏覽器地圖互動与部署後登入導向。
