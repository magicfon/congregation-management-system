# ADR-0051：週中聚會退回先前版次

日期：2026-10-16
狀態：已由 ADR-0053 取代發布與進版規則（2026-10-17）

## 背景與確認

使用者詢問能否退回前一版，得知現有功能僅能查看歷史後，同意新增「選擇舊版 → 載入為草稿 → 確認後發布新版」的流程。此決策取代 ADR-0050 原先不提供還原的限制。

## 決策

- 管理員在版次選單選擇實際保存的版本，查看後按「退回此版為草稿」。包括最新已發布版，方便捨棄草稿改動。
- 操作前確認會取代目前草稿（含尚未儲存修改）；取消不改內容。成功後儲存舊版完整內容為草稿，切回草稿預覽，可繼續修改。
- 公開內容維持目前發布版，直到管理員按「發布新版」。已下架的週次仍保持下架。
- 歷史版本、原始發布日期與版號不變；例如目前第3版，退回第1版後發布為第4版。相對最後發布快照重新計算累積高亮，不沿用舊版的修改標記。內容未變沿用不增版規則。
- 後端以同週的版號尋找已保存快照，不接受客戶端提供的替代內容；不存在、非整數或缺失的舊版本拒絕操作。
- 沿用管理員權限、同源檢查與樂觀鎖，過期或並行請求不能覆蓋他人更新。不新增資料表。

## 驗證

使用記憶體資料庫測試退回後公開內容隔離、完整草稿內容、歷史保留、發布遞增與高亮、無效版號、過期與並行操作，以及下架週次退回後仍不公開；執行既有週中檢查與 TypeScript 檢查。
