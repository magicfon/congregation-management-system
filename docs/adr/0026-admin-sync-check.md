# ADR-0026：管理員一鍵同步檢查

狀態：Accepted，2026-09-30

使用者同意在後台提供「同步並檢查」，避免手動取得 CRON_SECRET。

- 儀錶板僅管理員顯示入口，沿用 POST /api/cron/sync-sheet 的管理員 session 授權，不改動權限或同步演算法。
- 一次點擊依序執行兩次真實同步，第一次可能匯入待處理變更；第二次所有計數為零、無錯誤才顯示檢查通過。
- HTTP 失敗、回應格式異常、錯誤或衝突立即停止，不自動重試。保留已收到的每次結果；連線失敗不宣稱同步未執行。
- 執行中禁用按鈕並阻擋同頁重複呼叫。結果顯示摘要，詳細計數展開查看。
