# ADR-0084：公眾演講公布欄的無邊框嵌入版

2026-10-28，已接受。

使用者要求公眾演講公布欄另有一個全螢幕、沒有邊框的介面，內嵌在舊版 Google 協作平台。

- 網址 `/bulletin/public-talks/embed`，免登入，與公布欄一樣公開。目前只開放公眾演講，其他分類回 404，需要時再加入白名單。
- 不包 `DashboardLayout`（AGENTS.md 規則 7 的例外）：沒有網站標頭、主選單、外觀按鈕，也不顯示 PDF 工具列（頁數、同步時間、原文件、全螢幕）與底部操作提示，只留文件本身填滿 iframe。
- 寬度填滿、上下捲動，不再整頁塞進畫面；iframe 高度有限時字才不會太小。電腦滾輪是原生捲動，Ctrl＋滾輪（含觸控板雙指）縮放；手機雙指縮放、拖曳不變。
- 固定淺色，配合 Google 協作平台頁面，不跟裝置或已存的外觀選擇。
- 每次從開頭顯示，不接續閱讀位置，避免外部頁面上的訪客停在舊位置。
- 網站目前沒有設定 `X-Frame-Options` 或 CSP `frame-ancestors`，任何網站都能嵌入，不另加標頭。日後若全站加防嵌入標頭，這個網址要排除。
- 不加入搜尋引擎索引（`robots: noindex`）。無資料庫、Sheet 同步或 LINE 變更。
