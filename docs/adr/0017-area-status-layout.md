# ADR-0017：區域狀況固定視窗版面

2026-09-26。使用者要求登入資訊移至側欄，並避免選取區塊後捲動整頁查看明細。

共用版面移除桌面登入資訊橫列；姓名與角色放在側欄下方，收合時可點圖示展開查看，手機從選單查看。區域狀況使用動態視窗高度，桌面左右並列地圖與明細，手機上下分割。地圖透過 ResizeObserver 配合容器調整，明細優先放在面板頂部；每次改選區塊重設明細捲動位置。申請與圖例放在明細下方，僅超長明細面板內捲動，保持地圖可見。

驗證：使用隔離測試資料檢查 1280×720 及 390×844，document 高度等於視窗高度；點選分區、明細顯示、勾選申請正常。測試頁於提交前移除。
