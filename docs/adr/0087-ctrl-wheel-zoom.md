# ADR-0087：電腦版改用 Ctrl＋滾輪縮放

2026-10-28，已接受。部分取代 ADR-0067 的電腦滾輪縮放。

使用者要求電腦版不要一般滾輪就縮放，改成按住 Ctrl 再轉滾輪才放大縮小；手機維持雙指縮放。

- 公布欄 PDF 閱讀器（含公眾演講嵌入版）與週中聚會節目表一致：一般滾輪是原生上下捲動，Ctrl＋滾輪（觸控板雙指縮放也會送出 Ctrl＋滾輪）在閱讀區內縮放，以游標為中心，範圍不變。
- 在閱讀區內按 Ctrl＋滾輪一律攔下，到達縮放上下限時也不會改成整頁瀏覽器縮放。
- 拖曳移動、節目表的鍵盤加減號與 0 還原不變。
- 操作提示改為「電腦 Ctrl＋滾輪縮放」。
