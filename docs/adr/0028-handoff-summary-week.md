# ADR-0028：快速交接摘要與本週行程

狀態：Accepted，2026-09-30

使用者同意優先新增快速交接摘要與本週行程，沿用目前傳道排程及進度資料。

- 地圖頁優先顯示本輪最近提交者、提交日期、原始交接備註及查看筆跡入口，同時列目前傳道者及下一筆預排。沒有備註時不推測接續位置；過去輪次不混入摘要。
- 儀錶板本週採台北日期的週一至週日，按預排日列出本人目前輪次、仍持有中的 planned／active 工作，沿用原有權限範圍。
- 週前尚未完成工作獨立顯示；未來週行程可展開。週內空白日清楚標示沒有安排，不暗示預排已自動開始。頁面載入及重新整理時重新取得台北今日日期。
- 無新資料表、無外部通知、不更動完成／分發日期及 Sheet 同步。
