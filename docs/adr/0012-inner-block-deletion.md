# ADR-0012：內洞作為可選取的內部區塊

2026-09-22，使用者要求內洞應為可選取的新區塊，並確認刪除後併回外層區塊、內洞消失。

## 決定

將每個內環呈現為獨立可點選的內部區塊，顯示外層編號與刪除後的歸屬。沿用刪除區塊及放大選取區按鈕。外層的頂點編輯仍可調整內環；內部區塊本次提供選取及刪除，不自行補出新區域編號。

內部區塊從當前草稿的內環衍生，保留父候選、部件與環的關係，不重複存一份共享邊界。刪除內部區塊實際移除父候選的內環，重算面積與配對；因此儲存並讀回後不會重建已刪除的小塊。既有雲端與匯入草稿無須遷移，載入即支援此操作。

內部區塊繪製在一般候選下層，避免遮住真正獨立的候選。若填滿會覆蓋既有候選或同候選其他部件，整筆拒絕，避免產生重疊。一般區塊刪除語意不變；保留復原、重做及樂觀版本鎖。

## 驗證

涵蓋 58 號原始八個內洞、刪除內洞的面積及環數、原資料不變、鄰近候選不變、重疊拒絕、實際 UI 選取／刪除／復原重做及儲存讀回。
