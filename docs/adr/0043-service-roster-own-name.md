# ADR-0043: 連結成員的個人姓名高亮

日期：2026-10-04
狀態：已接受

使用者要求 LINE 登入後依成員連結高亮自己的姓名。沿用既有登入 session 的 member ID（LINE 連結失效時既有 auth 會撤銷身分），以 service_people.memberId 找排班 person ID，不用姓名、LINE 暱稱或瀏覽者傳入的 ID 比對。已登入的同一成員使用帳密登入亦適用。

獨立私人 `/api/service-roster/me` 只回傳登入者自己的排班 personId，驗證帳號仍啟用且未刪除，不公開 memberId／LINE UID／資格。回應不快取並依 Cookie 區分。未登入、不存在連結、身分讀取失敗時不高亮，公开安排仍可正常載入。

本週及所有週次頁共用高亮姓名元件，以暖色底框與「我」文字標記，不只依顏色辨識；回到頁面／重新聚焦會重讀連結身分，避免登出或重新連結後沿用舊高亮。既有所有人瀏覽與手動姓名篩選不自動改變。
