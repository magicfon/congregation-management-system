# ADR-0137：週中節目表右上角自動顯示改版日期

## 狀態

2026-11-21 使用者回報：週中委派改版後，節目表右上角沒有顯示「幾號改版」也沒有底色。已實作。

## 背景

舊 Google 文件的作法是在節目表右上角手打「9/17更新」並塗上該次更新的底色。改用系統版次（ADR-0050）後，修改處會依版號自動上色，但右上角的日期標示仍只靠手打的「更新標示」備註，系統從未自動產生，所以改版後看不到是哪天改的。與 PR #33 刪除配色設定無關。

## 決策

- 節目表右上角自動列出紙面上仍有底色的各版（第2版起），依版號由舊到新排列，文字「M/D更新」，紅色粗體，底色與該版修改處相同。
- 日期取該版發布日（台北日期）；舊資料以補填的版次日期為準。編輯中的下一版草稿尚無日期，預覽時以今天日期顯示（發布時即記為今天）。
- 某版的修改全部被後續版本蓋過、紙面上已無該色時，不再列出該版。
- 公布欄、嵌入頁與編排頁（含查看歷史版次）都顯示；手打的更新標示備註保留不變。
- 列印頁目前不帶版次底色，本次不變。
