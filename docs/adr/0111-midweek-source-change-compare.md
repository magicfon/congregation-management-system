# ADR-0111：週中編排手冊更新後左右比對

2026-11-05，已接受。

## 背景

週中編排頁在 jw.org 手冊內容變動後顯示「手冊已更新，現有安排已保留」，但系統只記下草稿建立時的手冊指紋（`sourceHash`），同步時會直接覆蓋手冊，看不出改了什麼。使用者要求加一個按鈕，左右兩邊一邊舊版一邊新版。

## 決策

- `MeetingRecord.sourceSnapshot` 保存草稿所依據的手冊原稿：經文範圍與每項節目的段落、名稱、分鐘，不含人員。
- 建立草稿與「從最新手冊重建草稿」時存最新手冊；既有草稿只要手冊還沒變，下次任何操作時補存。
- 週中同步（`keepOldSource`）覆蓋手冊前，若內容變了且草稿還沒有原稿，先把舊手冊存進草稿紀錄。這樣現有資料在下一次手冊變動時也有舊版可比。
- 提示改成「手冊已更新，現有安排已保留。」加「查看手冊更動」按鈕，開啟左右兩欄視窗：左舊手冊、右最新手冊。依節目名稱以最長共同子序列對齊；多一項或少一項另一邊顯示「（沒有）」，改名的節目左右並排；名稱、分鐘、經文範圍不同皆標黃。
- 已跳出提示但沒存到舊手冊的週（本 ADR 前就變動的），左邊改用目前草稿，並註明自己改過的節目也會標成不同。
- 草稿與人員照舊不自動套用新手冊（使用者選擇手動調整），比對只用來看差異。

## 補充（2026-11-05）

正式資料有 7 週跳出提示，但都沒有存到舊手冊，比對時左邊用草稿。這些舊草稿的節目名稱外層有方括號（如「[初次交談]」），經文範圍用半形「-」，最新手冊則沒有外層方括號、用全形「－」，所以大多只是格式差異。比對改為忽略節目名稱外層方括號（詩歌編號「唱詩第[103]首」不受影響）與全形／半形連字號；忽略格式後沒有差異的週不再顯示「手冊已更新」提示。

## 取捨

不比對人員、講評分鐘與職務標籤，因為手冊沒有這些資料。「一鍵套用新手冊並沿用同名節目的人員」先不做，需要時再談。
