# ADR-0129：地圖分配手機版改為全螢幕地圖＋底部抽屜

2026-11-15，已接受。取代 ADR-0123 的手機版排版（電腦版不變）。

## 背景

使用者反映手機上看地圖查詢（LINE「傳道地圖」→ 地圖分配頁）仍太擠：地圖只剩畫面約三分之一，明細被派發／申請切換與「地圖資訊、設定、清單」三條收合標頭夾在中間，只露出一兩行。提出三個方案（全螢幕地圖＋底部抽屜、底部分頁、維持上下排版精簡），使用者選了底部抽屜。

## 決策

- 手機版地圖佔滿頁首以下的空間；色階與「已分發灰色」開關改成浮在地圖右上（全圖按鈕下方）的小卡，原本的色階列只在電腦版顯示。
- 底部抽屜平常收起，只露出重點卡：區塊名稱、每張地圖的天數、持有人或上次完成日、狀態，以及 ADR-0123 的領圖操作列（加入按鈕＋已選張數）。有拒絕拜訪時提示往上看明細。未選取時只顯示操作列提示。
- 點把手或往上滑展開抽屜（約 92% 高），內容就是原本的側欄（派發／申請切換、地圖資訊、設定、清單）。往下滑或點把手收起。把手只有箭頭，不加文字（2026-11-15 使用者要求）。
- 地圖資訊、設定、清單一次只展開一個，展開其中一個時其他自動收合（手機與電腦版都適用，2026-11-15 使用者要求）；選區塊時回到地圖資訊。
- 點地圖選區塊、輸入號碼跳轉時抽屜回到收起狀態；按「查看清單」會展開抽屜並打開清單。
- 展開時抽屜由下往上滑入，收起時往下滑到重點卡的高度就停、接著換成重點卡（約 0.3 秒；2026-11-18 修正：原本會滑到最底再跳出重點卡），不再瞬間出現或消失；系統開啟「減少動態效果」時不播動畫。網站手機版左側選單同樣滑入滑出，背景遮罩淡入淡出（2026-11-18 使用者要求）。

## 取捨

沒做可拖到任意高度的抽屜，只有收起／展開兩段，實作簡單、不和 Leaflet 的拖曳手勢互搶。收起時抽屜會蓋住地圖底部一小段，可拖曳地圖看到。
