# ADR-0116：移除傳道行程，管理者選單左右分組

日期：2026-11-06；狀態：已接受

## 移除傳道行程

使用者表示不需要「傳道行程」（`/schedules`）功能。移除頁面元件、`/api/schedules`、`/api/schedule-areas`、側欄連結與 LINE 選單格。`/schedules` 保留為轉址到我的看板，避免舊書籤 404。

資料表 `schedules`／`schedule_areas` 與既有資料不動，不做破壞性遷移。刪除成員時不再檢查「未來帶領的行程」，因為已無介面可取消；仍檢查持有地圖與未完成的傳道進度（ministryVisit）。成員頁移除「N 排班」計數。

## 管理者管理頁左右分組

延續 ADR-0115。弟兄管理頁改為 2×2：區域回報、地圖交接、傳道地圖、領圖申請。管理者管理頁左邊 2×2 放弟兄的四項，右邊 2×2 放管理項目（服務安排、週中編排、管理公告、成員管理），中間以虛線分隔。原本管理者專用的「地圖分配」「領圖申請（審核）」與弟兄的傳道地圖、領圖申請是同一頁，合併為左側兩格。

選單圖片改變，LINE 不能替已建立的選單換圖，因此狀態鍵與 alias 升為 v7（`line_rich_menu_v7_*`、`cms-v7-*`），部署後需再按一次「發布至 LINE」。
