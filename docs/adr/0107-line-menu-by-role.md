# ADR-0107：LINE 圖文選單改為雙頁標籤，依身分顯示管理頁

日期：2026-11-01；狀態：已接受

使用者要求不同身分在 LINE 官方帳號看到不同選單。先後考慮過依持有地圖動態切換、固定三版，最後定為「雙頁標籤」：一般頁所有人相同，管理頁只有弟兄看得到，弟兄與管理者的管理頁內容不同。不依持有地圖切換，避免選單一直變。

- 一般頁：公佈欄、我的看板、我的委派（訊息動作）、傳道地圖（`/area-status`，可申請個人區域）。
- 姊妹（含未設性別、未連結、停用、刪除）：只有一般頁、沒有標籤列，作為官方帳號預設選單。
- 弟兄（性別 `brother`）管理頁：區域回報、地圖交接、傳道行程、領圖申請（自己的申請進度）。原提案的「傳道回報」已依 ADR-0102（統一回報入口）轉址到區域回報，與第一格重複，改放領圖申請。
- 管理者（`role === 'admin'`，不分性別）管理頁：區域回報、地圖交接、地圖分配、領圖申請、服務安排、週中編排、管理公告、成員管理。

地圖交接原本打算等多數弟兄連結 LINE 再開，使用者決定放在管理頁先上線。

## 實作

共五個 rich menu：`sister`、`brother-general`、`brother-manage`、`admin-general`、`admin-manage`（狀態鍵 `line_rich_menu_v6_{key}`，舊 v4 選單不刪）。有標籤的四個選單上方 110px 是「一般｜管理」，用 `richmenuswitch` 動作切到 alias `cms-v6-{key}`，切換在 LINE 內完成，不經過網站。

發布沿用 ADR-0047 的發布鎖與 expectedCurrentId：建立五個選單並上傳圖片、建立或更新 alias、姊妹版設為預設，再以 bulk link 把現有弟兄與管理者綁到各自的一般頁。之後在成員改權限／性別／帳號狀態（成員編輯、人員設定、性別批次）、LINE 配對、待確認帳號連結或建立、刪除成員時，對該成員 link 到對應的一般頁或 unlink 回預設。五個選單都發布前不做個別切換；切換失敗只記錄，不擋原操作，可再按一次發布補綁。

LIFF 的 `view` 參數改為白名單對照表（`src/lib/liff-settings.ts`），未知值一律回看板。選單圖片由 `scripts/create-line-menu.cjs` 產生，`scripts/check-line-menu.cjs` 驗證尺寸、格子涵蓋、標籤 alias、網址與切換流程。
