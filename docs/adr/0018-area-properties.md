# ADR-0018：區域狀況的地圖屬性

2026-09-26。使用者確認管理員可暫停新申請與分發，保留目前持有人。

Area.dispatchEnabled 預設 true。管理員從區域狀況逐張修改，若色塊涵蓋多個編號，分別操作。停用不修改持有人、分發日、完成日與最後完成回報日。新申請、直接分發、批量分發及待審核准均檢查此欄位；收回維持可用。停用與核准競爭時依資料庫交易順序決定，已完成的分發保留。此欄位由系統管理，不寫回 Sheet，Sheet 同步不覆寫此欄位。

歷史回報先採唯讀（待使用者進一步確認編輯範圍）：管理員展開時以 sheetNo 篩選 Sheet「傳道區域回報」A/B/D/F 欄，顯示提交時間、姓名與完成日期；系統內 Report 另列最近 100 筆並標示總數。不改 Sheet，也不以歷史查詢改動完成日期。Sheet 讀取失敗須明示，不能將系統內紀錄冒充完整表單歷史。屬性以舊值作更新條件，避免覆蓋同時修改；所有屬性與歷史 API 限管理員。
