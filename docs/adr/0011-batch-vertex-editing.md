# ADR-0011：框選頂點、平滑及批次刪除

2026-09-22，使用者確認：框選只作用於目前選取區塊，平滑要同時圓滑輪廓及縮減頂點。

## 決定

新增獨立框選模式，拖曳矩形選取頂點，Shift 可追加，選取以黃色與數量呈現。切換模式、區塊或復原時清除選取，避免索引套用錯誤。批次刪除亦支援 Delete。

平滑提供輕微、標準、較強三種強度。只平滑所選連續段的內部頂點，固定未選點及與未選部分相接的端點；以鄰點加權平均圓滑，再以分段線段距離簡化。整環選取時保留至少三個分散錨點。原圖像素容差不隨縮放改變。

一次修改可跨同候選的多部件與內洞。全部結果一起檢查自交、內洞、重疊；不合法則整筆拒絕。保留既有復原／重做、背景備份、雲端版本檢查與儲存後讀回流程。

## 驗證

涵蓋部分連續段、跨首尾索引、全環、不同環、非連續選取、至少三點、自交／內洞／重疊拒絕及原資料不變。測試實際 UI 的框選、批次操作、復原重做與儲存讀回。

2026-09-22 更新：依 ADR-0013，平滑後保留存活頂點選取；不同候選區塊允許重疊。仍檢查單一候選內的幾何有效性。
