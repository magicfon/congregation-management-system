# ADR-0066：公布欄分類改用漢堡選單

2026-10-23，已接受；取代 ADR-0065。

ADR-0065 上線後，使用者改選漢堡選單。公布欄有些頁面會被當作外部嵌入畫面，標題越簡單越好，不應兼作互動元件。

## 決策

- 分類頁標題回到純文字 `h1`。標題列右側放一顆 44px 的 ☰ 按鈕（無障礙名稱為「公布欄分類」）。
- 點開後由右側滑出抽屜，寬 18rem，最多占畫面 85%，背景加暗。清單列出七個分類，每列是圖示加名稱，目前分類加底色和勾號，每列至少 48px 高。
- 點背景、抽屜內的關閉鈕、按 Escape 或選定分類都會關閉。開啟時焦點移到關閉鈕，關閉後回到 ☰。
- 返回箭頭與首頁七分類入口保留。週中聚會閱讀頁維持原本無分類列的版面。公開公布欄本身沒有全站側欄的漢堡，因此不會出現兩個漢堡。

## 後果

標題在嵌入情境保持乾淨；切換分類需要多點一次 ☰。清單沿用公布欄分類圖示，未新增色彩或字體。
