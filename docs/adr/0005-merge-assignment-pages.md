# ADR-0005: 合併人員分配與使用中地圖

日期：2026-09-20
狀態：已接受

## 背景

兩頁都使用 `/api/areas/dispatched` 顯示按人員分組的使用中地圖；人員分配另有管理員批量收回及備註顯示。使用者同意保留功能後合併入口。

## 決策

- 將管理員逐張勾選、按人員全選及跨人員批量收回整合至使用中地圖，保留分配備註。
- 全選僅涵蓋該人員目前篩選結果，被篩選隱藏的勾選清除；送出前列出地圖供確認。
- 收回使用既有 admin-only API，不改變分發日期或後端同步語意；送出期間停用重複操作，失敗保留選取供重試，成功重新載入清單。
- 移除舊導航與專用元件，舊頁面保留為轉向以支援書籤；保留該路徑的登入保護。

## 後果

同一頁承擔查看、提醒與收回，避免重複維護；一般成員不顯示收回控制項。
