# ADR-0016：成員領圖申請與管理員審核

2026-09-26。使用者要求熱力圖預設將已分發地圖顯示灰色，並開放成員選最多五張地圖，經管理員同意後分發。

## 流程

兩個選圖入口共用申請 API 與待審額度。每人全部待審合計最多五張（實作預設），單次 1–5 張；可跨三區，重複待審同一張會拒絕。身份只取 session 的 member id，成員必須啟用。地圖仍可由其他人申請或由管理員直接分发，申請不預留。

新增領圖申請頁：成員看自己申請並可取消待審，管理員看待審與結果，可逐張核准／拒絕（實作預設）。核准時沿用可分發性、成員有效性與完整快照檢查；狀態變更與分發同一 Serializable 交易，重複或競爭核准回 409。提交／審核皆重新檢查狀態，不信任客戶端身份及上限。

交易成功後沿用 C/D 與 snapshot 寫入；Sheet 失敗時明示 DB 已分發、待同步，不撤回或重複核准。拒絕／取消不改分配。變更不改最後完成回報日期。採 map_requests 表與待審部分唯一索引，透過部署 migration 建表。

熱力圖灰色只改顯示，不改三區全域最大天數；多編號色塊若有使用中區域則整塊灰色，明細逐號顯示可申請性。取消灰色選項不代表使用中地圖可以申請。

## 驗證

申請身份與角色、停用成員、上限及重複、無效地圖、交易隔離、重複核准、已分發冲突、申請取消所有權；兩個入口提交、管理頁審核與灰色切換。只使用 mock DB／Sheet 驗證寫入，部署後以匿名請求驗證權限。
