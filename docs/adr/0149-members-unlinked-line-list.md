# ADR-0149：成員管理上方列出尚未連結 LINE 的成員

2026-11-26，已接受。

## 背景

使用者要求成員管理頁上方顯示尚未連結 LINE 的成員，方便知道還有誰要請他用 LINE 登入。名單上雖已用琥珀色「○ 未綁定 LINE」標示（2026-11-24 成員頁分色），但要逐列找。

## 決策

- 只給管理員：成員管理頁標題下方、「待確認 LINE 帳號」之上新增「尚未連結 LINE：N 位」區塊，列出姓名。
- 範圍是啟用中、未刪除、沒有 LINE UID 的成員；停用的不列。依姓名排序。
- 名單取自頁面既有的成員列表（未搜尋時的完整名單），不受搜尋框影響，不新增 API。
- 點姓名會把搜尋框填入該姓名，篩選下方名單，方便編輯；連結 LINE 仍由成員先用 LINE 登入，再於「待確認 LINE 帳號」連結。
- 全部都已連結時顯示「所有啟用中的成員都已連結 LINE」。

## 後果

- 不改資料與 LINE 流程；連結或新增成員後名單隨列表重新整理。
