# ADR-0132：週中編排頁列印節目表

2026-11-15，已接受。

## 背景

使用者要求週中聚會編排頁可以列印節目表。

## 決策

- 編排頁頁首「查看公開頁」旁加「列印」按鈕，開出選週視窗：列出本週起各週（正在看過去週次時連同那一週），預設勾選目前顯示的那一週（本週，或選中的過去週次），可多勾幾週一次印。
- 印的是公布欄上的版本（已發布版），不帶版次更動的底色；還沒發布的週印目前的草稿。取消的週印「本週無聚會：原因」（ADR-0131）。
- 列印版面一週一張 A4 直式，只印節目表，側欄、按鈕、版次與取消等編輯控制都不印。節目表以 1200px 原版排版整頁縮小到 A4 寬度，並強制印出段落色塊。
- 做法：按下列印後讀取所選各週，把節目表放進 body 底下的列印區，`body.printing-midweek` 時列印媒體只顯示列印區，印完（afterprint）移除。

## 取捨

不另開列印專用網址：沿用編排頁登入與權限，少一個頁面要維護；代價是列印區要靠全域 CSS 隱藏其他畫面。原本節目表的 `@media print` 窄版規則改成只套用在畫面上的節目表（`.viewport` 內），避免影響列印區。
