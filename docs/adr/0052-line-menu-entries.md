# ADR-0052：LINE 四格功能入口

日期：2026-10-16；狀態：已接受

使用者確認選單僅保留四格，依左上、右上、左下、右下排列：「公佈欄」「我的看板」「我的委派」「傳道地圖」。經詢問確認，「傳道地圖」開啟地圖交接功能。

公佈欄開啟 `/bulletin`；我的看板開啟 `/dashboard`；我的委派開啟 `/bulletin/service-roster/all?tab=mine`，預選本人服務安排；傳道地圖開啟 `/dashboard?view=handoffs`，沿用既有交接清單與地圖進度入口。LIFF 登入保留上述目的地；舊私訊指令及舊 LIFF 入口仍可使用。

選單狀態 key 升為 v3，發布時建立新版圖片及動作，避免沿用舊選單。沿用現有發布鎖、目前預設選單比對及原選單保留機制。
