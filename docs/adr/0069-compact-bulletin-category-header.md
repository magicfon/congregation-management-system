# ADR-0069：公布欄分類頁精簡上方區域

2026-10-23，已接受。

使用者附截圖指出分類頁上方疊了五層：網站標頭（楠梓會眾／公布欄、外觀、☰）、返回加分類標題列、文件卡標題加「開啟原文件」、同步時間、頁數加「全螢幕」，PDF 內容被推到畫面下半部。使用者要求整合這些區域。

## 決策

- 分類頁的網站標頭左側改為「← 分類名稱」，分類名稱是頁面的 `h1`；右側維持外觀控制與 ☰ 主選單。首頁與其他公開頁仍顯示「楠梓會眾／公布欄」。
- 移除分類頁內獨立的標題列。
- PDF 文件卡只保留一列工具列：左邊是「N 頁 · 同步／更新 MM/DD HH:mm」（分類有多份文件時，前面加文件名稱），右邊是「開啟原文件」與「全螢幕」兩個 44px 圖示按鈕，兩者都有無障礙名稱與提示文字。非 PDF 來源維持原本的標題加按鈕樣式。
- 手機版外觀按鈕只顯示圖示，640px 以上才顯示「淺色／深色」文字。
- PDF 閱讀區高度改為畫面高度扣掉上方區域（最少 360px），整頁放入的計算（ADR-0068）會隨之放大頁面。

## 後果

上方區域從約 450px 縮到約 150px（390px 寬的手機）。開啟原文件從文字按鈕改成圖示，需要靠圖示辨識；保留 title 提示與無障礙名稱。
