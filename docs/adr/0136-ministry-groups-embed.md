# ADR-0136：傳道組別公布欄的無邊框嵌入版

2026-11-20，已接受。

## 背景

使用者要求傳道組別也比照公眾演講（ADR-0084）與週中聚會（ADR-0085）提供嵌入頁，放進舊版 Google 協作平台的 iframe。

## 決策

- 網址 `/bulletin/ministry-groups/embed`，免登入，加入嵌入頁白名單。
- 與公眾演講嵌入頁相同：只顯示傳道小組試算表轉出的 PDF，不包 `DashboardLayout`、無標頭與工具列，寬度填滿上下捲動，固定淺色，每次從開頭顯示，`robots: noindex`。電腦 Ctrl＋滾輪（含觸控板雙指）縮放，手機雙指縮放。
- 不顯示捲軸（沿用 ADR-0114 的 `bulletin-embed-no-scrollbar`）：PDF 頁寬跟著框內寬度，組別表可能只有一頁、高度接近 iframe 高度，捲軸時有時無會讓頁寬來回跳而抖動。仍可用滾輪、拖曳或滑動捲動。
- 公眾演講與週中嵌入頁不變。
- 無資料庫、Sheet 同步或 LINE 變更。
