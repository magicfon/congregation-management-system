# ADR-0125：LINE 管理頁領圖申請格改為我的區域

2026-11-14，已接受。修訂 ADR-0122 的管理頁版面。

## 背景

使用者覺得 LINE 管理頁「傳道地圖」和「領圖申請」重複：兩格都在處理拿地圖，而且傳道地圖頁本來就能選地圖、提交領圖申請。空出的格改放弟兄更常用的「我的區域」。

## 決策

- 「領圖申請」格改為「我的區域」（副標「持有地圖與回報」），開 `/dashboard?view=maps`，捲到我的看板的「我的地圖」段落：列出持有的地圖、持有天數、拒訪筆數，展開可看小地圖與提交區域回報。不另做新頁，沿用看板既有內容。LIFF view 為 `maps`。
- 領圖申請併入傳道地圖：提交申請照舊在傳道地圖的申請清單；傳道地圖頁新增「領圖申請」連結到 `/map-requests`（查看自己的申請進度，管理者在同頁審核）。電腦版放頁首；手機版頁首空間不夠，放在未選地圖時的說明下方，申請清單內的「查看申請」連結保留。
- 弟兄與管理者管理頁同樣更換，位置不變（左下第二格）。
- 選單圖片改變，狀態鍵與 alias 升為 v10（`line_rich_menu_v10_*`、`cms-v10-*`），部署後需在「我的看板→管理工具→底部圖文選單」再按一次「發布至 LINE」。

## 不變

- 一般頁與姊妹版選單不變；側欄「領圖申請」與待辦中心的審核入口不變；`/map-requests` 頁與 LIFF view `requests` 保留，舊連結仍可用。
- 沒有勾選「可派發」的成員看板不顯示我的地圖，點我的區域會落到我的委派（既有行為）。
