# ADR-0135：我的委派固定列出本週狀態

2026-11-17，已接受。

## 背景

使用者要求我的看板「我的委派」一定要看得到本週的狀態；本週沒有委派時要明寫「本週沒有委派」。原本列表只列本週起的前三個日期，本週沒有委派時直接從下週開始，看不出本週是空的。

## 決策

- 每個分類分頁（弟兄服務／節目委派，姊妹只有一份）最上方固定一段「本週 M/D–M/D」，本週為台北時間週一到週日。
- 與本週日期重疊的委派列在這段；沒有就顯示「本週沒有委派」。
- 下方「接下來」列本週之後的委派，維持前三個日期、其餘收在「更多委派」；沒有則顯示「暫無已公布委派」。
- 標題列「本週起 · N 項」與過去委派不變。LINE「我的委派」私訊不變。
