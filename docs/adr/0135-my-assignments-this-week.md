# ADR-0135：我的委派固定列出本週狀態

2026-11-17，已接受。

## 背景

使用者要求我的看板「我的委派」一定要看得到本週的狀態；本週沒有委派時要明寫「本週沒有委派」。原本列表只列本週起的前三個日期，本週沒有委派時直接從下週開始，看不出本週是空的。

## 決策

- 列表最上方固定一段「本週 M/D–M/D」，本週為台北時間週一到週日。
- 與本週日期重疊的委派列在這段；沒有就顯示「本週沒有委派」。
- 下方「接下來」列本週之後的委派，維持前三個日期、其餘收在「更多委派」；沒有則顯示「暫無已公布委派」。
- 標題列「本週起 · N 項」與過去委派不變。LINE「我的委派」私訊不變。

## 修訂（2026-11-17）

使用者要求弟兄服務和節目委派一起顯示，不要分兩個標籤，避免漏看。

- 拿掉「弟兄服務／節目委派」分類標籤（ADR 先前的分頁），看板所有委派依日期排成同一份列表；本週、接下來、更多委派、過去委派都是合併後的結果。
- 每項上方的分類字（服務安排／週中聚會）保留，用來區分。
- 「本週委派」區塊加藍色粗外框與淡藍底、標題放大，比其他區段醒目。
- 姊妹原本就只看到節目委派，不變。網址 `?kind=` 參數不再使用。
- LINE「我的委派」私訊仍分弟兄服務、節目委派兩段，不變。
