# ADR-0097: 地圖頁面改名

日期：2026-10-29
狀態：已接受

## 決策

使用者要求：

- `/map`（原「地圖分配」，地圖清單）→ 畫面名稱「地圖列表」
- `/area-status`（原「區域狀況」，熱力圖、派發與申請）→ 畫面名稱「地圖分配」

只改使用者看得到的文字：側欄、頁面標題、瀏覽器分頁標題、領圖申請頁的選圖連結與錯誤訊息。網址、元件與 API 命名維持原樣，避免書籤、LINE 連結與既有程式失效。系統名稱「地圖分配系統」不變。

## 後果

舊 ADR 與 CONTEXT.md 舊條目中的「地圖分配清單」指現在的地圖列表，「區域狀況」指現在的地圖分配頁；程式碼註解與檔名（area-status）沿用舊稱。
