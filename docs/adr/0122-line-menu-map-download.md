# ADR-0122：LINE 管理頁原地圖交接格改為地圖下載

2026-11-12，已接受。修訂 ADR-0120 的管理頁版面。

## 背景

地圖交接關閉後（ADR-0120），使用者希望 LINE 管理頁原本「地圖交接」那格改放「地圖下載」，讓弟兄在 LINE 直接開地圖圖檔下載頁。

## 決策

- 新增選單格「地圖下載」（副標「區域地圖圖檔」），開啟 `/map-images`（地圖圖檔頁，免登入，可預覽及下載各區與全圖圖檔，ADR-0046）。LIFF view 為 `map-images`。
- 版面回到地圖交接時的位置：弟兄管理頁 2×2＝區域回報、地圖下載／傳道地圖、領圖申請；管理者管理頁左 2×2 同弟兄四格、右 2×2＝服務安排、週中編排／管理公告、成員管理，中間虛線分隔。
- 選單圖片改變，狀態鍵與 alias 升為 v9（`line_rich_menu_v9_*`、`cms-v9-*`），部署後需在「我的看板→管理工具→底部圖文選單」再按一次「發布至 LINE」。

## 不變

- 一般頁與姊妹版選單不變；地圖交接仍關閉。
