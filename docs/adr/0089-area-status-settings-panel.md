# ADR-0089：區域狀況側欄拿掉回報紀錄、設定改為獨立收合區

2026-10-28，已接受。補充 ADR-0083。

使用者反映區域狀況下方資訊欄可視範圍太窄，要求精簡地圖資訊。

- 地圖資訊內每張地圖的「回報」按鈕與回報紀錄（表單／系統）整個移除。屬性 API 的 GET 也不再讀取 Sheet「傳道區域回報」與系統回報，只回分類、開放分發與拒絕拜訪。
- 「設定」從地圖資訊內的按鈕改成側欄第三個收合區（僅管理員），位於地圖資訊與派發清單之間，預設收合。展開後顯示目前選取區塊每張地圖的分類、開放分發與拒絕拜訪設定；未選區塊時提示先點地圖。
- 派發模式下拿掉「為成員直接派發地圖」說明文字；申請模式的「最多 5 張」與超過 5 張的提醒保留。
