# ADR-0025：傳道排程、局部進度與交接

狀態：Accepted，2026-09-30

使用者確認領取者為地圖管理者，管理者可預排日期與傳道者，同時僅一位，由管理者指定下一位。傳道者可塗畫完成範圍，只提交局部進度；管理者確認整張完成後交回。

## 實作決策

- 每次安排為 MinistryVisit：planned → active → submitted，另可 cancelled。管理者／系統管理員可預排、取消、交接；僅該筆傳道者可儲存／提交筆跡。預排不會自動取代尚在進行中的傳道者。
- 輪次由地圖領取者與 dispatchedAt 決定；所有寫入驗證目前持有狀態與輪次，收回／轉交／重新分發後舊排程不可操作。舊輪次資料保留供管理者查看。
- 同輪次進行中筆數以 PostgreSQL partial unique index 限制；Area.ministryRevision 加版本比較，所有操作在 Serializable transaction 中完成，防止跨裝置覆蓋。
- 筆跡使用小地圖上的 0–1 正規化座標與相對筆寬，不修改原圖。每次提交獨立保存傳道者姓名、預排日期、提交時間與備註。既有已提交筆跡唯讀；傳道者可以存草稿、復原或清除自己的未提交筆跡。
- 畫圖與瀏覽工具分開；平板支援雙指縮放／平移。沒有小地圖時明示，仍可用文字回報進度。
- 儀錶板分開列出本人管理的地圖與被指派的傳道任務。新頁在 /map/ministry/[id]，沿用已保護的 /map 前綴與 DashboardLayout。
- 整張交回只允許管理者／admin，須無進行中任務，取消未開始預排；建立系統完成紀錄並套用 collect。Sheet 清 C 保留 D，快照仍須全 213 區。局部提交與系統交回不直接改寫 lastReportedCompletedAt（Google 表單來源）。
