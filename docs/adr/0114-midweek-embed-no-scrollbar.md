# ADR-0114：週中嵌入頁不顯示捲軸

2026-11-06，已接受。

## 背景

使用者回報 `/bulletin/midweek-meeting/embed` 在 Google 協作平台裡會抖動，連視窗放到最大也一樣。節目表依框內寬度自動縮放（`MeetingSheet`），捲軸一出現就吃掉寬度，縮放變小、內容變矮，捲軸又消失，寬度變回來，如此來回循環。

## 決策

- 嵌入頁（外層與節目表框）不顯示捲軸，仍可捲動：手機用滑動，電腦用滾輪或拖曳。
- 拿掉外層的 `scrollbar-gutter: stable`，捲軸不佔寬度，節目表寬度不再隨捲軸變動。
- 只改週中嵌入頁；公開頁、編排頁與公眾演講嵌入頁不變。
- 無資料庫、Sheet 同步或 LINE 變更。
