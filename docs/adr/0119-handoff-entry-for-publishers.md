# ADR-0119：被交接的傳道者也能從「地圖交接」進入

2026-11-08，已接受；2026-11-09 被 ADR-0120 取代（地圖交接整個關閉）。

## 背景

領取地圖的人（地圖管理者）和實際被交接、出去傳道的人常常不是同一位（ADR-0025）。LINE 管理頁的「地圖交接」開啟看板的「待交接」，那裡只列本人管理、等著交接出去的地圖。被排到但沒有領圖的弟兄看不到排給他的地圖；ADR-0116 移除傳道行程後，原本的本週行程元件也沒有頁面使用。LINE 通知只有文字，連結指向看板首頁。看板設成不顯示派發的弟兄，按下去會被導到我的委派。

使用者確認：姊妹領的都是個人區域，只需自己領完回報，不參與交接。

## 決策

- 看板新增「排給我的地圖」區塊：列出本人在目前輪次中預排（等待交接）或進行中（已交接給我）的地圖，點下去開交接頁。只要有資料就顯示，不受「顯示於派發」影響（不派發的弟兄也可能被交接）；沒有資料就不出現。
- `/dashboard?view=handoffs`（LINE「地圖交接」）有排給我的地圖時先捲到這個區塊，其下仍是原本的「待交接」。
- 預排、改期、交接開始、提交進度的 LINE 通知附上該張地圖交接頁連結；改派他人與取消的通知連到看板的地圖交接區。
- 交接頁「預排傳道」的傳道者下拉只列啟用中的弟兄；API 也擋下安排姊妹或未設性別的成員。既有資料不變。

## 影響

- 無資料表變更、無 Sheet 同步變更，LINE 選單不需重新發布。
