# ADR-0041: 服務安排顯示與管理分頁

日期：2026-10-03
狀態：已接受

使用者要求「安排跟顯示的頁面要分開」。公開 `/bulletin/service-roster` 僅提供週次瀏覽與原表參考，登入管理員只見「管理安排」連結，不讀取管理快照、不提供編輯或資格操作。獨立 `/service-roster/manage` 頁提供編輯、補空缺、新增週次、人員資格及安排統計，保留大字與亮暗配色，並可返回公開頁。

管理頁在 middleware 要求登入，伺服器檢查管理員角色；非管理員導回公開頁。管理 API 既有角色、同源與版本衝突驗證仍是每次讀寫的權限邊界。共用排班元件的明確管理模式，不以登入本身切換公開頁的用途。
