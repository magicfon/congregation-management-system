# ADR-0108：區域狀態 D 欄的公式不當分發日期

2026-11-04，已接受。

## 背景

使用者發現有人用舊系統（Google 表單）回報後，「區域狀態」的分發日期變了。查 Sheet 發現 56、57、58、72 區的 D 欄被填成 `=TODAY()`，每天顯示當天日期。每 15 分鐘的同步把它當成「Sheet 手動改了分發日期」匯入，系統的分發日期也天天往後跳，而且清掉交回紀錄（completedAt）。使用者要求回報不應改動區域狀態表格，最多收回負責弟兄。

## 決策

- 同步時另外以 FORMULA 模式讀 D 欄；D 欄是公式的列，不把公式算出的值當分發日期。
  - 持有人（C 欄）沒變：沿用上次同步的日期，不算 Sheet 有改。
  - 持有人換了：以當下算出的日期為分發日期（等同當天分發）。
- 同步後把這些公式格寫回固定日期，C 欄不動。

## 取捨

不追查公式是誰填的；Google 表單本身只寫「傳道區域回報」，若綁有 Apps Script 改 D 欄，需使用者在 Sheet 的 Apps Script 停用該段。已被公式帶動的錯誤日期需另外更正。
