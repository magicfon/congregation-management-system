# ADR-0150：成員管理顯示 LINE 通知開關狀態

2026-11-28，已接受。

## 背景

使用者要求成員管理多一個欄位，顯示該成員是否開啟 LINE 通知。系統已有成員自己的主動通知開關 `members.lineNotificationsEnabled`（預設開啟，成員在我的看板切換）；關閉時地圖、委派、學生通知單、提醒等 LINE 私訊都不發。

## 決策

- 「LINE 通知」以 `lineNotificationsEnabled` 為準，只給管理員看：電腦版表格在「LINE 名稱」後新增一欄，手機版卡片顯示在 LINE 名稱下方。
- 三種狀態：未連結 LINE 顯示「—」；已連結且開啟顯示綠色「✓ 通知開啟」；已連結但關閉顯示紅色「✕ 通知已關閉」。
- 管理員只看不改，開關仍由成員本人切換。
- 不偵測是否封鎖官方帳號（LINE 沒有可靠的即時查詢），被封鎖的仍顯示開啟。

## 後果

- 成員 API 的管理員欄位多回傳 `lineNotificationsEnabled`，不新增查詢。

## 修訂（2026-11-28）

使用者要求能把關閉通知的人篩選出來。搜尋框旁新增「只看關閉通知（N）」切換按鈕（只給管理員），按下後名單只列已連結 LINE 但關閉通知的成員，可與搜尋併用；在前端篩選，不改 API。
