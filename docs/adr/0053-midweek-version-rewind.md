# ADR-0053：週中聚會退回原版號與重新進版

日期：2026-10-17
狀態：已接受（使用者確認退回一律保留，僅進版前詢問刪除）

## 決策

取代 ADR-0051「還原內容發布為新一版」的規則。退回已保存版本先取代草稿，公開頁直到再次發布才變更；若未改內容，退回第1版再發布就是第1版，不增版，該版的原日期與欄位高亮保持不變。

- 明確記錄草稿基準版與目前發布版，不再把歷史清單最後一筆當作目前版本。既有資料沒有新欄位時沿用最後一筆，無需資料庫遷移。
- 退回時一律保留所有後續版本，可在管理頁查看或重新選取；下架週次退回後維持下架，直到管理員發布。
- 草稿有內容變更時，以草稿基準的當前版本 + 1 發布。若有更高版本，按發布時先列出將刪除的版次範圍，確認才刪除後續快照及該範圍的補填日期，並建立新版；取消則不改草稿、不刪除、不發布。
- 後端檢查明確的刪除確認旗標，缺少旗標即拒絕有後續版本的進版。刪除與發布在同一次樂觀鎖更新內完成，過期／並行操作不能刪除別人的新版本。
- 版本配色為全站設定，刪除某週後續版本不影響配色。重新進版的高亮相對當前基準計算，不引用已被刪除版本的標記。
- 公開頁固定呈現目前發布版的內容與高亮，不能因保留較高歷史版本而誤顯示其內容。管理頁明示目前發布版與草稿基準版，避免把保留的歷史最高版當成當前版。
- 未變更且已發布的同一版維持「沒有變更，不需發布」；下架後重新發布同版恢復可見性，不增版。

## 驗證

使用記憶體資料庫覆蓋退回不增版、退回發布不刪除歷史、保存草稿與重新載入、舊資料相容、公開內容／高亮一致、修改後須確認刪除、取消或過期請求不寫入、清理後續日期、並行發布只成功一次、重新從當前版加一及下架／重新發布。
