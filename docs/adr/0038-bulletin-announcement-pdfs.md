# ADR-0038: 管理員上傳 PDF 公告

日期：2026-10-03
狀態：已接受

## 需求與操作

使用者要求管理員可上傳 PDF 至會眾公告並自動渲染，確認保留多份公告、上傳即公開。網站持續免登入閱讀、介面精簡。

## 決策

- 公告頁辨識現有登入管理員，顯示標題、PDF 選檔及上傳按鈕。後端沿用 requireApiUser(['admin']) 驗證上傳及下架；一般成員與訪客不得修改。
- 每份限制 4,000,000 bytes，原始 PDF body 上傳，避免 Vercel 4.5 MB request 上限與 multipart 額外大小。檢查副檔名、PDF 標頭及結尾；失敗不建立公告。
- 使用既有 Neon Bytes 欄位保存，無須新增 Blob 權杖或雲端服務。標題、檔案、作者 ID 與發布時間同一筆建立，避免只有公告而沒有檔案。
- 公開清單僅含標題、ID、大小與時間，最新優先。第一份自動展開，其他點開才載入 PDF，避免同時下載全部公告。
- 閱讀器接受明確指定的本站 PDF URL，沿用多頁捲動、雙指縮放與位置記憶。新公告使用新的 ID 和內容版本。
- 下架為軟刪除，保留資料可恢復。PDF 路由不快取下架結果前的回應，公開請求每次檢查有效狀態；已下載至裝置的內容無法遠端撤回。
- 保留原 Google 公告頁入口，新的 PDF 公告不寫回 Google。
