# ADR-0033：管理員待辦中心

日期：2026-10-01
狀態：Accepted

使用者同意優先製作管理員待辦中心，集中待確認 LINE、待審領圖申請與待交接地圖。採儀錶板頂部三張摘要卡＋分類清單；只列真正未完成事項，不複製核准／配對的寫入操作。

- 僅 admin 顯示且 API 再驗證 admin。一般成員保留本人儀錶板，無權取得全會眾待辦。
- LINE 與申請回傳總數、最早五筆摘要；點選前往成員管理待確認區或對應申請列。摘要不回傳 UID、email、筆跡、自由文字備註。
- 待交接採全會眾目前持有地圖：本輪有 submitted、沒有 active；列目前管理者、最近提交者／日期及下一筆 planned。排除舊輪次、交回、僅預排無提交的地圖。網站個人待交接與管理員清單共用判斷。
- 顯示待交接全部數量，先展開五張，可查看全部；每張連到既有管理／傳道頁。管理員本人待交接已包含其中，不在儀錶板重複顯示。
- 載入、失敗與零待辦分開；頁面回到前景與手動重新整理時重讀資料。無 DB schema、分發、Sheet 或 LINE 發送變更。
