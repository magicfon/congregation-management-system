# ADR-0002: 人員分配總覽頁面

## 狀態
Accepted

## 背景
使用者需要一個介面查看「每個人員身上被分配到什麼地圖」，並能從這個介面直接收回地圖。

## 決策
- 獨立頁面，放在側邊欄新增導航項
- 所有 LINE 登入者可查看
- 收回/操作功能只有 admin 可用（role === 'admin'）
- 不顯示已收回的區域（completedAt > dispatchedAt）
- 顯示分發天數（只有有真實 dispatchedAt 才算）
- 支援批量收回
- 轉移 = 先收回再重新分配（兩步操作）

## 後果
- 側邊欄從 4 項變 5 項
- 需要新增 API endpoint 回傳按人員分組的分發資料
- 前端需要根據 role 顯示/隱藏操作按鈕
