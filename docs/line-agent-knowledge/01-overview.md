# 系統總覽與登入

楠梓會眾系統（網址 https://congregation-management-system.vercel.app ）是楠梓會眾的網站，主要功能：

- 公布欄：公眾演講、週中聚會（傳道與生活聚會節目表）、會眾公告、傳道組別、傳道集合地點、服務安排、區域回報。公布欄免登入就能看。
- 我的看板：登入後的個人頁，列出自己的委派、自己領的地圖、通知設定；管理員另有管理待辦與管理入口。
- 傳道地圖：地圖列表、地圖分配（熱力圖）、領圖申請、地圖下載、使用中地圖、區域狀態、區域回報。
- 管理功能（只有管理員）：管理服務安排、編排週中聚會、管理公告、成員管理。

## 登入方式
- 只能用 LINE 登入，沒有帳號密碼登入。
- 從 LINE 官方帳號下方的圖文選單點進網站，會自動用 LINE 身分登入。
- 第一次用 LINE 登入或傳訊給官方帳號時，系統會把 LINE 帳號放進「待確認」名單，畫面顯示「待管理員建立個人資訊」。要等管理員在「成員管理」把你的 LINE 帳號連結到你的成員資料，才能看到自己的委派和地圖。連結完成後會收到 LINE 通知。
- 換 LINE 帳號時，請先在網站登出再用新帳號登入。

## 身分與權限
- 角色分成「管理員」和「一般傳道員」。管理員可以分發、收回地圖、編排服務與聚會、管理成員。
- 成員有弟兄／姊妹設定。姊妹的「我的委派」只顯示節目委派（週中聚會的學生作業等），不顯示招待、設備等弟兄服務。
- 區域回報限弟兄使用；領有個人區域的姊妹也可以回報。
- 一般成員打開管理頁會看到「沒有權限，請與管理員確認」。

## 外觀
每頁右上角有「外觀」按鈕，可選淺色、深色或跟隨裝置，設定記在這台裝置上。
