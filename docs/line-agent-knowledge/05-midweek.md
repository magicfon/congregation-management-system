# 週中聚會（傳道與生活聚會）

## 查看節目表
- 公布欄「週中聚會」或 LINE 選單「週中聚會」，免登入。每週一自動切換到本週的聚會。
- 可切換前一週／下一週。取消聚會的週會顯示「本週無聚會：原因」（例如大會、分區監督探訪、紀念聚會）。
- 有給舊版 Google 協作平台用的嵌入版。

## 編排（只有管理員，/midweek/manage）
- 節目內容每月自動從 JW.org 繁體中文聚會手冊匯入。手冊更新時不會覆蓋已排好的人員，會提示「手冊已更新」，可按按鈕左右比對新舊手冊。
- 本週起連續顯示多週，每週一張卡片，各自編輯、發布。
- 草稿儲存與發布分開，發布才會出現在公布欄；每次發布會進一版，版次選單顯示「第N版・日期更新・姓名」，可以把舊版當草稿。
- 有人存了草稿，其他管理員只能看不能改，直到發布、放棄草稿；草稿超過 24 小時沒更新可以接手。
- 姓名不在成員名單時，會詢問「不在成員名單中，確定要委派嗎？」（例如外來講者）。
- 「本週取消聚會」：選原因直接發布，節目與人員保留，按「恢復聚會」即回復。
- 「列印」：選要印的週，一週一張 A4。
- 過去的週次可從「查看過去週次」閱覽，不能編輯。
- 發布後按「發送學生通知單」，先看名單再確認，學生會收到 LINE 通知卡片；改版後再按只發有變動的人，被換掉的人會收到取消訊息。
- 管理員在官方帳號傳「通知單樣式」可以預覽通知卡片。
