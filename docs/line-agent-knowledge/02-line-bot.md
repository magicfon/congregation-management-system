# LINE 官方帳號怎麼用

## 圖文選單
聊天室下方的圖文選單依身分不同：
- 一般頁（所有人相同，8 格）：公眾演講、週中聚會、會眾公告、傳道組別、集合地點、服務安排、我的看板、我的委派。
- 姊妹（以及還沒連結帳號、未設定性別的人）只有一般頁。
- 弟兄多一個「管理」標籤：區域回報、地圖下載、傳道地圖、區域狀態。
- 管理員的「管理」標籤：左邊同弟兄四格（區域回報、地圖下載、傳道地圖、區域狀態），右邊是服務安排（管理）、週中編排、管理公告、成員管理。
- 改權限、改性別、連結或停用帳號後，選單會自動更換。

## 文字指令
直接傳這些文字，會立刻回覆固定格式的內容：
- 「我的委派」：列出本週起自己的服務安排與週中聚會委派。日期寫成「11月15日（日）」這種格式。完整與過去的委派請到網站「我的看板」。
- 「我的地圖」：列出自己目前領著的地圖（最多 20 張，多的請到網站看）。
- 「選單」：顯示簡單說明。

其他問題可以直接用一般文字問，例如「怎麼申請地圖？」「我下週有委派嗎？」「這週誰當招待？」，由 AI 小幫手回答。小幫手看得到全會眾已公布的服務安排、週中聚會節目與地圖持有狀況，以及你自己的委派、地圖和領圖申請；它會記得最近幾句對話，可以追問。每人每天可問 20 題，固定指令不受限。小幫手只能回答問題，不能替你申請地圖、回報或調換委派。

帳號還沒連結的人只能用固定指令。

## 通知
官方帳號會主動發送：帳號連結完成通知、週中聚會學生練習通知單（S-89-CH）、個人區域 30 天回報提醒等。通知開關在網站「我的看板」的 LINE 通知區塊。

## 學生練習通知單
週中聚會委派發布後，管理員在週中編排頁按「發送學生通知單」，學生本人會收到 LINE 卡片，卡片上有「收到」按鈕，按下後管理員就能看到「已確認」。助手不發通知。通知更新重發後需要再按一次收到。沒有綁定 LINE 的學生，由管理員用「通知單圖片」轉交。
