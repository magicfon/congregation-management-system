# 傳道地圖、領圖、回報

會眾共有 213 張區域地圖，分屬楠梓、橋頭、梓官三個地區。

## 地圖分類
- 一般區域：由管理員分發，或成員申請後由管理員審核。
- 個人區域：所有已連結的傳道員都可以申請，審核通過起算 30 天，到期前未回報會收到一次 LINE 提醒。
- 個人管理：固定由一位管理人持有，不分發、不能申請、不收回，管理人自己用區域回報記錄。

## 相關頁面
- 地圖分配（/area-status，LINE「傳道地圖」）：熱力圖，顏色代表距上次完成回報的天數（綠色最近、紅色最久、灰色沒有資料）。點地圖看資訊、最近三次回報、拒絕拜訪地址、下載圖檔。上方可輸入號碼直接跳到該地圖。會記住上次看的地區。
- 地圖列表（/map）：所有地圖依號碼排列，顯示閒置天數。
- 領圖申請（/map-requests）：查看自己的申請進度；管理員在這裡審核。
- 區域狀態（/territory-status，LINE 管理頁「區域狀態」）：現在誰領著哪些地圖、領了幾天，以及自己申請的狀態。所有登入成員都能看。
- 地圖下載（/map-images）：各地圖圖檔，免登入。
- 使用中地圖（/active-assignments）：依人員列出使用中地圖與領取天數（30–59 天黃色、60 天以上紅色）。

## 怎麼申請地圖
1. 開「傳道地圖」（地圖分配頁），在地圖上點選可領取的地圖，手機版下方有固定的操作列。
2. 每人待審的申請合計最多 5 張，按「申請」送出。
3. 管理員審核通過後地圖才正式分給你，可在「領圖申請」或「區域狀態」看進度；待審的申請可以自己取消。
暫停分發或已有人持有的地圖不能申請。

## 怎麼回報（區域回報）
1. 開公布欄「區域回報」或 LINE 管理頁「區域回報」（限弟兄；有個人區域的姊妹也可以）。
2. 填傳道時段、區域號碼（輸入號碼按 Enter 變成標籤，可一次回報多區，最多 20 區；自己領的地圖會列在下方可點選加入）、開始日、結束日、備註。
3. 結束日不能早於開始日、不能晚於今天；回報自己的地圖時，結束日不能早於領取日。
4. 回報自己領的地圖，送出後地圖自動交回。回報別人領的地圖要勾選確認，地圖不會交回，會交給管理員確認。未領取的地圖一般成員不能回報。
5. 只回報一區時，可以選填「拒絕拜訪地址」，管理員核准後才寫入。
回報會同步寫入會眾的 Google 試算表「傳道區域回報」。

## 拒絕拜訪地址
登入成員可在傳道頁上方紅框、我的看板的地圖卡片「拒訪 N 筆」、地圖分配的地圖資訊看到。只列文字，不在地圖上標點。

## 管理員操作
- 分發：在地圖分配選地圖，選成員（快捷按鈕或搜尋姓名）後分發。
- 收回：在使用中地圖或地圖分配收回。
- 撤銷派發：派錯人時用，地圖回到派發前狀態、不算完成。
- 暫停分發、個人區域／個人管理設定、拒絕拜訪地址：在地圖資訊的「設定」。
