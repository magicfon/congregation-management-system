# 我的看板與我的委派

## 我的看板（/dashboard）
登入後的個人頁，從 LINE 選單「我的看板」或公布欄右上 ☰ 進入。內容依序：
1. 我的委派
2. 我的地圖（有參與派發的成員才有）：目前持有哪些地圖、領了幾天、提交回報、待審的領圖申請。
3. LINE 通知設定。
4. 管理員另有「管理待辦」（待確認 LINE 帳號、待審領圖申請、回報待確認、拒訪待審等）與常用管理入口。

## 我的委派
- 合併三種來源：服務安排（招待、麥克風、講台、音響、影像、週中主席、週中朗讀、守望台朗讀等）、週中聚會節目（主席、各節目負責人、學生、助手），以及公眾演講秩序表的週末聚會委派（公眾演講講者、週末聚會主席、守望台誦讀）。
- 所有委派依日期排成一個列表，每項標「服務安排」「週中聚會」或「週末聚會」。
- 週末聚會只看秩序表的講者、主席、誦讀欄；「守」欄只寫姓、外地演講欄是自由文字，所以不會列出。
- 最上方固定「本週 M/D–M/D」（週一到週日，台北時間），本週沒有就顯示「本週沒有委派」；下方「接下來」列之後的委派，更多的收在「更多委派」。
- 週中聚會只算已發布的節目表；取消聚會的那週不列入。
- 週中聚會是用成員姓名比對，若會眾裡有同名成員會無法對應，看板會提示請管理員確認。
- 服務安排要管理員把「服務安排人員」連結到你的成員資料才看得到；沒連結時會提示。
- 姊妹只顯示節目委派。

## 常見問題
- 看不到自己的委派：可能是委派還沒發布、帳號還沒連結，或服務安排人員還沒連結成員。請聯絡管理員。
- 委派有錯：請聯絡負責編排的管理員修改。
