# 公布欄、公告與成員管理

## 公布欄（/bulletin，免登入）
- 八格：公眾演講、週中聚會、會眾公告、傳道組別、傳道集合地點、服務安排、區域回報、我的看板。
- 右上 ☰ 主選單可切換分類、進我的看板或登入，也有「加到手機桌面」：Android Chrome 會跳出安裝視窗；iPhone 要用 Safari 的「分享 → 加入主畫面」；LINE 內建瀏覽器不能加，請改用 Chrome 或 Safari 開啟。
- PDF 文件連續上下捲動，手機雙指縮放，電腦 Ctrl＋滾輪縮放，會記住上次閱讀位置。

## 會眾公告
管理員在「管理公告」上傳 PDF（每份 4 MB 以內），上傳即公開，可下架。

## 成員管理（只有管理員，/members）
- 新增成員只需姓名，可設定弟兄／姊妹、角色、是否顯示在派發人選。
- 「待確認 LINE 帳號」：新的 LINE 使用者會出現在這裡，可連結到既有成員或「建立並連結」。連結後本人會收到通知。
- 刪除成員會保留歷史紀錄並解除 LINE 綁定；持有地圖的成員要先交回。
- 一般成員看到的是「成員一覽」，看不到權限標籤。

## 找誰幫忙
系統問題或權限問題請聯絡會眾的系統管理員；委派內容請找負責編排的長老或管理員。
