📖 使用說明

🆕 v2.2 更新（2026-03-22）

  • ✨ 新增自動貼齊功能：手動畫邊界後，一鍵貼齊紫色線
  • 🎯 編輯模式下點擊「🎯 自動貼齊紫色邊界」按鈕
  • 📏 最大貼齊距離 100px，自動搜尋半徑 200px（可擴展至 400px）
  • 📊 添加 console.log 調試信息（按 F12 查看）

v2.1.1 更新（2026-03-22）

  • 🐛 修復 HSV 參數：參考 CV2 Python 代碼調整容差
  • ✨ H 容差 × 4，S/V 最小值 30（避免灰階）
  • 📊 添加 console.log 調試信息（按 F12 查看）

v2.1 更新（2026-03-22）

  • ✨ 智慧套索重大改進：HSV 色彩空間 + 形態學處理
  • 🔧 膨脹+侵蝕算法連接斷線（模擬 OpenCV）
  • 🎯 多輪廓檢測，自動選擇最近的封閉區域
  • 🔍 過濾小面積雜訊（< 1000px²）
  • 📊 紫色邊界檢測準確度大幅提升
  • 👁️ 瀏覽模式：查看和選中區域，拖拽平移地圖
  • ➕ 新增模式：
    • 點擊地圖 = 新增矩形區域
    • Shift+點擊 = 畫多邊形（雙擊完成）
  • 🎯 智慧套索（改進版）：
    • 第一步：抽取顏色 - 點擊地圖上的目標顏色（如邊界線）
    • 第二步：追蹤邊界 - 再次點擊區域，自動追蹤該顏色的邊界
    • 改進算法：使用 HSV 色彩空間 + 形態學處理（膨脹+侵蝕）連接斷線
    • 可調整容差範圍（5-50）來匹配相近顏色
    • 點擊「🔄 重置」可重新抽取顏色
  • ✏️ 編輯模式：
    • 點擊區域選中後可修改編號
    • 拖拽頂點 = 調整形狀
    • 拖拽中心 = 移動區域
    • 點擊邊線 = 添加新節點
    • 右鍵點擊節點 = 刪除節點（最少保留3個）
    • 🎯 自動貼齊紫色邊界：選中區域後，點擊按鈕自動將頂點貼齊最近的紫色線（距離 < 100px）
  • 🗑️ 刪除模式：點擊區域刪除
  • 縮放：使用 +/- 按鈕或滑鼠滾輪
  • ☁️ 雲端：載入地圖時自動從雲端載入已保存標注
  • 智能編號：重複編號會自動加上後綴（如 5-1, 5-2）
